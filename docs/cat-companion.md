# LifePath 고양이 동행

## 범위와 완료 조건

2026-11-01 사용자 승인: 사진의 흑백 고양이를 2D 캐릭터로 만들어 LifePath 웹사이트 상단에서 걷게 한다. 기존 6프레임 걷기 시안을 사용한다.

- 헤더 위의 전용 공간에서 좌우로 걷고 끝에서 방향을 바꾼다. 폼이나 계산 결과 위로 겹치지 않는다.
- 고양이를 클릭하거나 키보드로 활성화하면 잠깐 멈추고 인사한다.
- 멈춤/재생과 숨김/복원을 제공하며 설정은 해당 브라우저에만 저장한다. 저장소 접근이 차단되어도 기능은 동작한다.
- 기기의 `prefers-reduced-motion` 설정을 존중한다. 탭이 숨겨지거나 캐릭터가 화면 밖에 있으면 애니메이션 루프를 중지한다.
- 컴포넌트 해제 시 타이머, animation frame, 이벤트 구독, observer를 정리한다.
- 이미지가 로드되지 않아도 금융 화면을 계속 사용할 수 있어야 한다.
- 데스크톱과 320px 이상 모바일 화면에서 가로 넘침이 없어야 한다.

## 구현 경계

입력은 사용자의 클릭·기기 설정·화면 크기이고 출력은 시각적 애니메이션과 표시 설정이다. 금융 입력, API, 계산 엔진, 가정, 정답은 변경하지 않는다. 외부 AI/API 호출이나 계좌 데이터 사용은 없다. 드래그·점프·여러 마리·추가 동작은 이번 범위에서 제외한다.

## 파일

- `frontend/src/components/cat-companion.tsx`: 독립 클라이언트 컴포넌트와 수명주기 관리.
- `frontend/src/components/cat-companion.module.css`: 컴포넌트에 한정된 반응형 스타일.
- `frontend/public/mascot/lifepath-cat-walk.webp`: 사용자 사진을 참고해 ImageGen으로 제작한 투명 6프레임 아틀라스의 웹용 압축본. 시안과 동일한 무늬·비율을 유지하며 밝은 배경에서도 합성한다.
- `frontend/src/components/financial-planner.tsx`: 기존 헤더에 컴포넌트 연결.
