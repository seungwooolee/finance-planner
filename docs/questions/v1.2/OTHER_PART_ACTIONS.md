# 다른 파트 조치 및 미완료

엔진: DEBT-INPUT-1.2.1의 납부총액(원금+이자+비용), 이자·비용 개별값, balance_as_of, balance_timing, payment_period, pay_on을 명시 접수해야 한다. 현행1.3-engine monthly_payment는 원금+이자다. 비용을 임의 누락하거나 납부총액으로 의미를 바꾸어 전달하면 안 된다. 상환후 잔액에 상환전 원금 비교를 적용하면 안 된다. 새 비용·시점 지원 전에는 원응답을 저장하고 관련 전망만 보류한다. 같은 기준의 상환전 원금·확인된 비용0 사례는 기존 엔진에서 정상 통과했다.

BE: 새1.2.1 원응답→1.3-engine 명시 어댑터와 source_ref·owner·기간·상태·revision 연결이 필요하다. 정의버전을 단순 치환하지 않는다. NOT_ENTERED/DEFERRED/DECLINED는 계산 시 UNKNOWN과 합쳐져도 원상태는 별도 보존한다. 저장기록 없음은 NOT_ASKED가 아니다. NEW-06 추가목표 방식은 정책 최소+추가액으로 고객총목표를 명시 변환한다. POLICY_ONLY를 확인한 경우만 추가0을 사용할 수 있다.

FE: 현행55 질문 폼·정밀 직접 진입·결과별 부족 필드 확장·같은 사실 캐시·모름의 보류 표시를 연결해야 한다. 실제 제품 UI E2E는 NOT_RUN이다. 기존 frontend의 기본 재무계획 화면을 새55 질문 UI로 간주하지 않는다. 이번 패치의 Python reference router/7개 경로 부담 수치는 제품 DOM이나 소요시간 실측이 아니다. 전체 세금·연금·상속의 중첩 필드 수는 실제 폼 연결 후 추가 집계해야 한다.

총괄: 통합본 Library v5, 엔진1.0/질문 실행정의1.3-engine/배정정책1.0을 기준으로 질문·결과1.2.1 패치만 병합한다. 기존 통합 ZIP과 엔진 파일은 이번 작업에서 교체하지 않았다. POC-01 초안은 그대로 보존했다. QD01~05와 기존 엔진에 있는 QD06 범위만 채택했다. R02/R04/R05/R06의 질문·계약 수정은 반영했고, R12의 실제 제품 UI 및 전체 중첩 필드 실측 완료는 FE 연결 후 재검증한다.
