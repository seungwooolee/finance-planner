## 2. 질문 보완: 목적과 위험선호를 구분

### 2.1 기존 질문을 유지하는 이유

UI-11-01의 ‘투자에서 무엇을 중요하게 생각하나요?’는 원금 변동 최소화·정기 현금흐름·균형·성장이라는 **투자 목적**을 묻는다. 정기 현금흐름이 필요하다고 위험선호가 높거나 낮다고 단정할 수 없으므로 이 문항을 직선적인 1~5 점수로 바꾸지 않는다.

기존 구 Q12 / UI-11-02의 가상 하락 행동은 유지한다. 구 Q32 최대손실 허용률을 다시 추가하지 않는다. 통합 Q-032 대출잔액과 통합 Q-122 생활영향은 유지한다.

### 2.2 신규 선호 문항 UI-11-09

고객 문구: **‘수익을 기대하는 과정에서 가격이 오르내리는 것을 어느 정도 받아들이고 싶나요?’**

도움말: ‘어떤 답이 더 좋은 것은 아니에요. 실제 투자할 수 있는 범위는 생활비·목표·자금 사용일을 함께 확인해 정해요.’

| --- | --- | ---: |
| MINIMIZE | ‘수익 기회가 작아져도 가격 변동을 줄이는 것이 가장 중요해요.’ | P1 |

저장 개념 필드: risk_tradeoff_preference, source_ui_id=UI-11-09, wording_version, original_answer. UI-ID는 영속 Q-ID가 아니며 최신 활성 질문 원장을 대조한 뒤 실제 매핑한다. 기존 답으로 이 새 응답을 추정해서 채우지 않는다.

### 2.3 하락 행동·응답 재확인

UI-11-02: ‘투자한 1,000만원이 일시적으로 800만원이 된다면 어떻게 하실 것 같나요?’

| 응답 코드 | v0.2 처리 | 해석 |
| --- | ---: | --- |
| sell_all | 행동 정보 | 전부 매도할 것 같음. 이유와 자금 영향 확인 |
| sell_some | 행동 정보 | 일부 매도할 것 같음 |
| hold | 행동 정보 | 유지할 것 같음. 고위험 상품 허용 근거가 아님 |
| buy_more | 행동 정보 | 추가매수할 것 같음. 등급 가점 없음, 별도 재원 확인 |
| unknown | 미확인 | 모름. 중립 점수로 채우지 않음 |

20% 하락은 응답 상황의 예시다. 상품 예상 손실·최대 손실·고객의 실제 감당한도를 뜻하지 않는다. 추가매수는 자금 여력이 필요하므로 별도 재원 검증 없이 실행 제안하지 않는다.

다음 조합은 자기보고 선호를 덮어쓰지 않고 행동의 맥락을 추가 확인한다.

| 조건 | 상태·화면 |
| --- | --- |
| GROWTH/HIGH_VARIATION이며 전부 매도 | 행동 맥락 확인. 성장 선호와 손실대응 전략은 양립할 수 있으므로 모순 확정 금지 |
| MINIMIZE/LIMITED이며 추가매수 | 행동 맥락·추가 재원 확인. 선호 유형을 올리지 않음 |
| 선호 응답 모름·미입력 | 자기보고 유형 null. 필요한 문항만 다시 연결 |
| 행동만 모름·미입력 | 자기보고 선호는 유지, 행동 확인은 미완료. 적합성에 필요한 결과만 보류 |

UI-11-10은 조건부 확인 화면이다. ‘상황에 따라 다르게 행동해요 / 손실대응 전략 때문이에요 / 생활·상환·목표에 영향이 있어요 / 답변을 수정할래요 / 아직 판단하기 어려워요 / 직접 설명’을 제공한다. 두 답이 모두 맞다는 설명도 원문으로 저장하며 더 공격적이거나 일관된 답으로 수정하도록 강제하지 않는다. 확인 후에도 자기보고 선호는 별도 유지하고 자금 영향·이해도·상품 제약으로 실행 가능 범위를 판단한다. 설명만으로 제약을 해제하지 않는다.

### 2.4 기간 미정의 후속 확인

기존 UI-11-05에서 ‘정해진 사용일 없음’을 선택했다고 무한 장기자금으로 보지 않는다. ‘계획상 적어도 언제까지는 사용하지 않을 수 있나요?’라는 조건부 날짜 확인을 제공한다. 미정이면 기간 제약이 필요한 구성은 보류한다. 이는 매도·인출을 금지하는 계약이 아니라 현재 계획의 사용시점 입력이다.

## 3. PREF-0.2 자기보고 선호와 행동 확인

### 3.1 점수 합성 폐기

v0.1의 S=min(T, 0.7×T+0.3×A), 70:30 가중치와 20점 간격 컷오프는 현행 처리에서 사용하지 않는다. 검토 결과 점수화 가능한 16개 조합 중 14개가 선호 한 문항의 유형과 같아, 별도의 다차원 진단으로 설명할 근거가 부족했다.

v0.2는 고객이 선택한 다섯 선호 표현을 P1~P5의 자기보고 표기로 직접 연결한다. score=null, classification_source=SELF_REPORTED, assessment_status=PROVISIONAL로 반환한다. 검증된 투자성향 진단·규제상 적합성 판정을 대체하지 않는다. 자금 여력·기간·상품 적합성은 별도로 검토한다.

| 선호 응답 | 자기보고 유형 | 고객 표시 |
| --- | --- | --- |
| MINIMIZE | P1 | 안정형 선호 |
| LIMITED | P2 | 안정추구형 선호 |
| BALANCED | P3 | 중립형 선호 |
| GROWTH | P4 | 적극투자형 선호 |
| HIGH_VARIATION | P5 | 공격투자형 선호 |

선호유형은 인격·성공가능성·자산관리 실력의 등급이 아니다. 점수를 높이는 것이 목표가 아니다. 모름·상충·정책 미활성 상태를 P3로 채우지 않는다.

### 3.2 행동 응답의 처리

| 자기보고 유형 | 전부 매도 | 일부 매도 | 유지 | 추가매수 |
| --- | --- | --- | --- | --- |
| P1 | P1 | P1 | P1 | P1 + 맥락·재원 확인 |
| P2 | P2 | P2 | P2 | P2 + 맥락·재원 확인 |
| P3 | P3 | P3 | P3 | P3 + 재원 확인 |
| P4 | P4 + 맥락 확인 | P4 | P4 | P4 + 재원 확인 |
| P5 | P5 + 맥락 확인 | P5 | P5 | P5 + 재원 확인 |

이 표는 선호를 바꾸지 않는 저장·분기 계약이다. 모든 조합이 실제 투자에 적합하다는 뜻이 아니다. 행동·생활영향·이해도·상품정보가 부족하면 해당 적합성 결과는 계속 확인 필요다. 과거 숫자 점수는 이력으로 보존하되 현행 응답의 진단점수로 표시하지 않는다.

### 3.3 응답 저장·유효성

입력값·원문·버전·시점·재확인 이력을 남긴다. 고객 재무상태·목표·자금 사용일이 바뀌면 자금 제약을 재계산한다. 일반 선호의 재응답 여부는 변경 이유와 유효성 정책을 따르며 과거 선호를 무단 수정하지 않는다. 문서에 없는 ‘1년 또는 2년 동안 무조건 유효’ 같은 서비스 규칙을 임의 적용하지 않는다.

고객에게는 자기보고 유형과 의미·사용한 응답·수정 경로를 제공한다. 해당 선호 표시가 고위험 상품 허용이나 적합성 확정이 아님을 구분한다.

현재 잔액 500만원과 앞으로 월 30만원을 530만원의 현재 투자금으로 만들지 않는다. 월 적립은 매 납입시점의 재원·제약에 따라 처리한다. 자금별 만기·결제·계좌 출금제약도 확인한다.

### 4.2 먼저 적용하는 제약

| 제약 ID | 조건 | 처리 |
| --- | --- | --- |

| CAP-04 | 실제 지급일의 사용가능 잔액이 음수 | 해당 계획·자금의 실행불가. 부족일·금액 표시 |

| CAP-06 | 기간·제한·보유노출·필수정책 미확인 | NEEDS_INPUT / REVIEW_REQUIRED. LLM으로 값을 만들지 않음 |
| CAP-07 | 검증된 신규 투자재원 0원 | 신규 제안금 0원. 현황·기존 보유·실행계획 유지 |
| CAP-08 | 매도 미허용 또는 세금·비용 미확인 | 신규 납입만으로 가능한 경로, 그렇지 않으면 조정 보류 |

고객이 ‘보호금 0원’을 선택했다고 재무적으로 충분히 보호된 것으로 간주하지 않는다. POL-FIN-1.0의 고객 선택 보호목표와, 투자 실행 정책에서 확인할 필요 보호재원은 별도 필드다. 후자의 기준이 없으면 적합성 REVIEW_REQUIRED다. 가상 사례에서 6개월을 사용한 사실을 운영 공통 하한으로 만들지 않는다.

### 4.3 재무상태 기반 손실 여유

복잡한 자금은 기간별 필수지급·보호·목표·현금화 경로를 포함한 검토 모형이 필요하다. 그 산출값을 PREF 점수나 고객의 기분으로 채우지 않는다. 자료·검토 방법이 없으면 loss_budget=null과 REVIEW_REQUIRED다.

이번 단순 검산에서는 보호·목표자금이 따로 완전히 확보되고, 투자금 전액을 잃어도 그 자금을 다시 꺼낼 필요가 없다고 **가정한 장기자금 W**를 사용한다. 이 제한된 가정에서 재무상태상 손실 여유의 상한은 W다. ‘고객은 W를 잃어도 괜찮다’는 권고·심리 평가가 아니다. 실제 운영의 손실 여유를 무조건 투자금 전액으로 저장하지 않는다.

모형의 스트레스 허용액은 min(검토한 재무 손실 여유, W×실험적 유형별 스트레스 상한)이다. 두 값의 출처·버전을 각각 남긴다. 스트레스 상한은 구 Q32의 고객 최대손실률을 되살린 값이 아니다.

## 5. 자금기간별 범위

v0.1의 ‘5년 이하 CASH100% / 5년 초과 주식 최대60% / 10년 초과 최대80%’는 폐기한다. 기간 하루 차이만으로 주식 비중이 0%에서 60%까지 바뀌는 결과를 실제 적합성으로 설명할 근거가 없었다. 새로운 임의 가중치나 곡선으로 그 자리를 채우지 않는다.

| 자금의 성격·기간 | v0.2 처리 |
| --- | --- |
| 보호금·필수지급·금액 보전이 필요한 목표 재원 | 장기 위험투자 mandate에서 제외. 사용가능일이 맞는 현금·예금 등의 조건을 별도 확인 |
| 사용 예정일이 기준일 이전 또는 오늘 | 투자가 아니라 지급 준비·부족 검증. 구성 제안 보류 |
| 보호재원 외의 투자 후보 자금 | 확인한 사용일·변경 가능성·필요금액·상품 만기·환매·손실 영향을 기간정책에 전달 |
| 기간정책이 검증·버전 관리됨 | 해당 자금·상품에 적용 가능한 범위만 후보 탐색에 사용 |
| 기간정책이 미정·미검증 | REVIEW_REQUIRED와 PERIOD_POLICY_UNVALIDATED. 금액·현황은 유지하고 비중 확정 보류 |
| 사용일·최소 사용가능기간 미정 | 장기로 가정하지 않고 확인 필요 |

기간은 실제 날짜·사용가능일로 계산한다. 기간정책 계약은 policy_id, version, approval_state, applicable_scope, required_inputs, equity_cap 또는 상품별 허용조건, evidence_refs, boundary_sensitivity_result를 포함한다. 필요한 정책이 없으면 임의 상한을 기본값으로 넣지 않는다. 과거 날짜·오늘 지급·기간 미정은 서로 다른 상태로 보존한다.

검산 fixture에서 기간상한을 명시 입력해 탐색기를 확인할 수 있지만 source=FIXTURE_ONLY로 구분한다. ‘10년이 넘었다’는 사실만으로 상한80%를 자동 생성하지 않는다. 향후 기간정책에는 경계 전후 날짜의 구성·위험 차이와 원인을 검증하는 사례가 필요하다. 필수 목표 재원은 기간이 길어도 보호 조건을 우선한다.

채권펀드도 가격·금리·신용 위험이 있고, 예금 만기는 지급일과 맞아야 한다. MMF·초단기 ETF·CMA의 모든 유형을 예금과 동일한 보호상품으로 묶지 않는다.

## 6. ALLOC-0.1 후보 자산군과 연구용 기준형

### 6.1 세 자산군의 의미

| 모형 자산군 | 이번 검산 대용자산 | 실제 상품 연결 시 필요한 확인 |
| --- | --- | --- |
| EQ | 광범위 글로벌 주식 노출의 합성 대용자산 | 시장·국가·통화·상위종목·집중도·환헤지·거래·비용·자료 권한 |
| FI | 원화 우량 단기 채권의 합성 대용자산 | 실제 신용·듀레이션·만기·금리·손실·환매 조건. ‘단기’ 명칭만으로 통과 금지 |
| CASH | 원화 현금의 합성 대용자산 | 실제 예금·현금성 상품의 원금·보호범위·기관·인출조건·비용 별도 |

ETF는 상품 형태이고 EQ·FI는 실제 노출 분류다. ISA·연금은 계좌형태다. 실물 금융상품을 선정한 카탈로그는 아직 없으므로 EQ·FI·CASH의 계산값은 바로 주문할 상품 비중이 아니다.

### 6.2 연구용 선호 기준점

**아래 비율은 이번에 명시적으로 제안한 실험값이다. 실제 고객 권장 비중이나 승인된 운영 정책이 아니다.** 이전 Excel의 P1=10/70/20 등 고정비중과 별도의 버전이며 고정 코어·위성 배분은 사용하지 않는다.

| 유형 | EQ 기준점 | FI 기준점 | CASH 기준점 | 스트레스 비율 상한 |
| --- | ---: | ---: | ---: | ---: |
| P1 | 0% | 0% | 100% | 0% |
| P2 | 20% | 50% | 30% | 8% |
| P3 | 40% | 40% | 20% | 15% |
| P4 | 60% | 30% | 10% | 25% |
| P5 | 80% | 10% | 10% | 35% |

상한은 선택한 스트레스에서 기준을 통과하는지 살피는 내부 실험 수치다. 고객이 실제로 감수할 수 있는 최대손실을 확인한 수치가 아니며 손실을 이 비율로 제한해주는 장치도 아니다. P1의 0%는 CASH 가격충격을 0으로 놓은 합성모형의 조건일 뿐 현실의 무위험 보장이 아니다.

### 6.3 탐색 규칙

1. EQ·FI·CASH를 5% 단위로 나눈 합계 100%의 231개 후보를 만든다. 5%는 해석·검산을 위한 해상도이며 최적 거래단위가 아니다.
2. EQ는 min(유형 기준 EQ, 확인한 기간정책 상한, 환노출 상한) 이하로 제한한다. 기간정책 미검증이면 이 단계에서 REVIEW_REQUIRED를 반환한다. 임의의 5년·10년 컷오프나 기본80%를 사용하지 않는다. 합성 검산의 EQ는 비헤지 외화노출100% 가정이며 실제 환노출은 별도다.
3. CASH는 10% 이상이다. CASH를 제외해야 하는 조건과 충돌하면 억지로 다른 자산에 편입하지 않고 후보 없음으로 처리한다. 이 10%도 연구용 모형 조건이지 일반 권고 비율이 아니다.
4. 제외 자산군 비중은 0이다. FI 허용 조건이 확인되지 않으면 FI 비중 0 경로만 검토한다. 현금 조건까지 불명확하면 합성 현금 대안과 실상품 추천을 구분한다.
5. 기간·보유·매도 제약과 스트레스 한도를 모두 적용한다. 비용 차감 전 결과와 비용 후 결과를 섞지 않는다.
6. 통과 후보 중 연구용 기준점과의 **제곱거리 합이 최소**인 구성을 선택한다. 미래수익률이나 샤프지수 최적화가 아니다.
7. 동률이면 EQ 기준점과의 차이가 작은 후보, CASH가 큰 후보, FI가 작은 후보 순으로 선택한다. 같은 자료·정책에서 같은 결과가 나와야 한다.
8. 후보가 없으면 0개와 구체적인 충돌 사유를 반환한다. 제약을 느슨하게 바꿔 통과시키지 않는다.

기준점에 가까운 것이 고객에게 최선임을 증명하지 않는다. 이 방법은 설명 가능한 초기 연구모형이며, 투자성과·위험·고객 적합성 검증 결과에 따라 기준형·탐색 규칙 모두 변경 가능하다.

## 7. STRESS-0.1 합성 시나리오

| 시나리오 | EQ 원화 평가 충격 | FI 평가 충격 | CASH 평가 충격 |
| --- | ---: | ---: | ---: |
| S1 주식 급락·채권 동반 손실 | −40% | −6% | 0% |
| S2 금리·주식 동반 충격 | −15% | −12% | 0% |
| S3 주가·환율 복합 | −32% | 0% | 0% |

S3의 EQ는 외화 주가 −20%와 환율 −15%를 가정해 (1−0.20)×(1−0.15)−1=−0.32로 계산했다. −20%−15%=−35%로 단순 합산하지 않는다. 실제 상품은 헤지·거래소·환율·비용에 따라 달라진다.

세 시나리오는 정책 산술 확인을 위해 만든 가정이다. 역사적 최대하락·발생확률·최대 예상손실·신뢰수준을 뜻하지 않는다. 실제로 더 큰 손실·유동성 동결·발행기관 문제·동시 보호자산 손실이 발생할 수 있다. 미래수익률은 이 문서에서 입력하지 않는다.

시나리오 s의 손실률=max(0,−각 자산군 비중×해당 평가충격의 합). 최대 시나리오 손실액=W×세 시나리오 중 가장 큰 손실률이다. 실제 검증에는 상품별 비용·환매제약·현금흐름까지 반영해야 한다. 이번 합성 검산의 거래·세금 비용은 0이라는 fixture 가정이다.

| P3 | 30% | 45% | 25% | 14.7% | 147만원 |
| P4 | 55% | 30% | 15% | 23.8% | 238만원 |
| P5 | 80% | 10% | 10% | 32.6% | 326만원 |

P2의 가장 큰 손실은 S2의 10%×15%+50%×12%=7.5%다. P3은 S1의 30%×40%+45%×6%=14.7%다. P3의 기준점 40/40/20은 S1 손실 18.4%로 연구용 15% 한도를 넘어서 그대로 채택되지 않는다.

P3의 1,000만원은 EQ 300만원+FI 450만원+CASH 250만원이다. 이 금액은 이미 분리한 보호금·목표금에 다시 합산하지 않는다. CASH 250만원도 투자계정 안의 현금이며 기존 비상금에 중복 가산하지 않는다.

## 9. 기존 보유·산업·상품 연결

### 9.1 기존 보유와 신규 납입

현재 유지하기로 한 동일 mandate의 자산 W_old와 지금 실제 들어갈 신규금 W_new를 구분한다. 총액 W=W_old+W_new로 목표금액을 계산할 때 목표금액−기존금액이 음수면 해당 자산군 매도가 필요하다. 매도 미허용이면 그 후보는 불가다.

예: P3의 EQ 상한이 40%인데 기존 EQ가 총 대상금의 80%이고 매도도 허용하지 않으면, 이를 해결한 것처럼 보이는 신규매수표를 만들지 않는다. 추가 현금으로 희석할 수 있는지 별도 금액·시간 대안을 검토하거나 후보 없음으로 반환한다.

기존 보유가 합계로만 있으면 자산군 내부 중복·통화·산업 적합성을 알 수 없다. 상세가 없는데 전체 적합성 ALLOWED를 반환하지 않는다. 합성모형 탐색의 기존비중은 대사된 입력 범위만 사용한다.

### 9.2 산업 선호의 역할

산업선호 0~3개는 산업 분석·기업 비교에 사용한다. 이번 초기 배분모형의 테마·개별주식 자동 편입비중은 0이다. 관심 산업을 분석해도 편입하지 않는 결과가 가능하다. 기존 고정 위성 비율이나 산업 수 균등배분은 재도입하지 않는다.

산업을 포함하는 후속 정책은 시장 대비 실제 노출·기존 보유·국가·통화·상위종목·유동성·비용·세금·집중 상한을 함께 검토해야 한다. ‘ETF 2개’라는 상품 개수만으로 분산됐다고 보지 않는다.

제외 산업이 광범위 지수에도 들어 있을 수 있다. 실제 구성자료가 없으면 ‘제외조건 준수’를 확정하지 않는다. 상품·산업·기초자산 태그를 확인한 카탈로그가 필요하다. 제외정보와 산업 전망 긍정이 충돌해도 제외조건을 우선한다.

## 10. 금액·반올림·재점검

EQ·FI의 배정금은 W×비중을 원 단위 내림하고 남은 원을 CASH에 둔다. 이후 원 단위 실제 비중으로 제약·최소금액·매도 미허용을 다시 검사한다. 이 규칙이 거래 가능한 수량을 보장하지 않는다.

가격·최소거래단위·비용을 확인한 뒤 수량을 만들면 미체결·잔여금·정수주 제약을 추가한다. 미확인 상태에서 수량·주문서를 출력하지 않는다. 고정 현금 비중을 맞추려 기존 자산을 동의 없이 매도하지 않는다.

재점검은 입력·목표·소득·보유·상품조건의 중요한 변화, 실제 실행과 계획의 차이, 자료 만료·정책 변경이 있을 때 새 run으로 한다. 자동 리밸런싱 주문은 이 범위가 아니다. 무조건 잦은 매매를 생성하는 정책도 두지 않는다. 기간이 짧아져 구성이 달라지면 비용·세금·매도 권한과 원목표 재원을 다시 확인한다.

### 11.1 결과를 분리해 반환

정책 미활성·상품 없음·자료 미확인을 하나의 ‘후보 0개’로 뭉치지 않는다. 후보 집합이 실제로 비어 있으면 충돌한 제약을 제시한다. 기본 A~D 현황·목표·재무실행 결과는 계속 제공한다.

## 15. Codex에 전달할 구현 계약과 다음 단계

이번 작업은 설계·독립 계산 검산이다. 앱·저장소를 변경하지 않았다. Codex는 기존 AGENTS.md·질문 원장·API를 먼저 확인하고 버전 어댑터로 연결한다.

- 현행 PREF-0.2는 자기보고 선호 표기다. ALLOC-0.2·STRESS-0.1의 실제 추천은 여전히 검증 전이며 기간정책 미검증 결과를 보류한다. 과거 PREF-0.1 합성점수는 비활성 이력으로만 보존한다.
- 정책 숫자는 별도 테이블·버전으로 관리한다. LLM이 점수·비중·세율·제약을 덮어쓰지 못한다.
- 기존 UI-11-01 목적, UI-11-02 하락행동, UI-11-06 생활영향은 보존한다. UI-11-09와 조건부 재확인·기간확인은 실제 Q-ID와 매핑 후 적용한다.
- 제16절의 현행 수정 검산을 우선 적용한다. INV-01~40은 v0.1 역사 재현용이며 새 버전의 정답으로 사용하지 않는다. 산술·분기 통과와 실제 금융 적합성은 별도다.
- 같은 고객의 보호·목표·장기자금을 분리하고, 미확인·후보없음·정책 미활성을 각각 표시한다.
- 실제 상품·자료·권한·세금·비용·제공범위를 검증하기 전에는 모델 비중을 주문·매수권고로 연결하지 않는다.

**다음 우선 산출물은 대표 고객 한 명의 입력→진단→계획 비교→이번 달 실행을 잇는 시연·검산 명세다.** 상품·ETF 카탈로그와 실제 투자정책 검증은 해당 사례의 필요 범위에서 연결한다.
