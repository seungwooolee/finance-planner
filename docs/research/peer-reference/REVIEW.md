## 구현

- `scripts/import_peer_research.py`는 스냅샷을 Decimal로 정확 정규화하고 조사표 등록값과 일치 여부를 확인한다. 12.3456만원=123456원, 큰 정수·실제0/null 보존, 원 미만 조용한 반올림 거부. 재생성 명령: 프로젝트 Python으로 `scripts/import_peer_research.py`.
- 독립 `backend/app/planning/peer_reference_data.json`에 원문 단위·정의·연도·통계유형·집단·한계·자료 버전을 등록한다. 기존 투자 정책/카탈로그와 분리한다.
- `question_bridge`의 기존 미리보기/저장 공통 경로에서 `peer_reference`를 추가한다. 결과의 입력 해시·버전·기준일·자료 해시가 묶여 기존 `result_json`에 저장된다. 과거 저장 결과의 통계를 조회 시 덮어쓰지 않는다. 추가 DB 마이그레이션 없음.
- LIFE-01의 확인된 primary/overlaps는 탐색 후보 순서만 바꾸며 자동 매칭하지 않는다. 범위/정의/기간 확인이 부족하므로 수치 차이·상대율은 null이다. 개인/부부와 가구의 값은 연결하지 않으며 원 자산 결과 또는 presentation gate가 보류하면 내 값도 보류한다.
- 현재 재무 상태: 집단 명시 선택 → 15개 공개 참고값, 평균/중앙값, 원문 링크·기준기간·정의·한계 확인. 가구의 총자산·부채·순자산만 기존 결과의 동일 개념 값을 별도로 나란히 표시한다. 세전 연소득을 월 실수령액으로 나누지 않는다.
- 투자선호 화면: 원 문항/분류·이용조건이 없어 직접 연결하지 못한 이유와 원문 링크. 외부 5분류를 DION 5선호로 자동 대응하거나 비중/위험등급을 생성하지 않는다.
- 이전 버전 결과에 이 필드가 없으면 재계산 안내를 표시한다. stale 결과는 이전 입력 기준임을 표시하며 새 입력을 가져오지 않는다.
