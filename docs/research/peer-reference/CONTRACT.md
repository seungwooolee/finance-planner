# 생활단계 참고 통계 연결 1.0

2026-11-16: 결과의 주 생활단계를 탐색 기준으로 쓴다. 사회초년생은 가구주 29세 이하(C20), 은퇴기는 가구주 60세 이상 자료를 기본 참고한다. 이는 실제 나이·은퇴 여부나 동일 가구원 수를 확인한 결과가 아니다. 신혼기·양육기는 해당 집단에 확보한 참고 지표만 표시하며, 총자산·순자산 자료가 없으면 이를 표시한다. 결과 화면에서 이 결과의 개인 범위가 1인 가구 전체와 같다고 명시 확인하면, 엔진이 계산한 동일 항목을 참고값 옆에 표시한다. 확인은 해당 결과의 화면 상태에만 적용한다. 기존 저장 자료에 개인 비교용 금액이 없는 경우 새 계산이 필요하다. 새 가구주 29세 이하 자료는 2025년 공식 부록의 총자산·순자산 중앙값을 이용하며, 부채 보유 가구만의 중앙값은 등록하지 않는다.

2026-11-15 보완: 사용자 승인에 따라 공식 부록의 C08/C09 부채·순자산 평균/중앙값 6행을 별도 근거 파일로 추가했다. 원 28행/CSV는 보존하며 `dion-peer-reviewed-20261115-v2`는 34행이다. 직접비교 규칙·API 버전은 그대로다. [출처 셀·정밀도·표시 계약·검증](../../integration/2026-11-15-cohort-comparison.md)을 참조한다. 아래 28행은 원 v1 범위를 뜻한다.

2026-11-14 사용자 요청: 완료된 조사 검토 → 비교 데이터 등록 → 결과 연결 → FE 표시.

- 입력은 현재 결과가 캡처한 질문 원문과 엔진 결과다. LIFE-01 primary/overlaps와 context.scope를 재사용한다. 나이·경력·혼인기간·가구주 여부를 추정하지 않는다.
- 조사표 최신 28행(기존 JSON 20행 + 추가 8행)을 스냅샷으로 보존한다. S01/S03은 공식 PDF 첫 페이지의 공공누리 출처표시 유형을 확인하고 참고 표시만 허용한다. S02는 상업이용금지, S04/S06/S07/S08/S09는 이용조건 또는 원문/문항 검토가 남아 수치 노출 보류.
- 결과의 `peer_reference`는 독립 부가 출력이다. 데이터/규칙 버전·해시·입력 해시·집단·수치 ID·원문 단위·통계유형·기준기간·출처·한계를 함께 저장한다. 기존 엔진 산식/투자선호/배분/채택/원응답은 변경하지 않는다.
- 생활단계는 탐색할 자료 후보의 순서만 바꾼다. 화면에서 원래 집단을 명시 선택한다. 전체가구를 사회초년생 평균, 60세 이상 가구주를 은퇴 평균, 부부를 개인/가구전체로 바꾸지 않는다. 중첩 단계는 별도 후보이며 평균 합성 금지.
- 현행 입력에는 경력·가구주·혼인기간 및 통계와 동일한 포함범위 확인이 없다. 실자료는 REFERENCE_ONLY, 차이·상대율·순위는 null이다. 같은 개념의 내 값은 결과값 그대로 별도 표시하되 정의·기간 차이를 안내한다. 개인/가구 불일치 또는 원 결과 보류 시 내 값도 연결하지 않는다.
- 직접비교는 범위/집단/지표정의/기간/단위/분모가 모두 검토된 이후 별도 규칙 버전에서 활성화한다. 이번 버전에서 테스트용 계산기를 운영 직접비교로 오해하게 노출하지 않는다.
- 0/음수/미확인을 보존하고 금액 정규화는 Decimal 정확 문자열로 처리한다. 원 미만은 반올림하지 않고 등록 오류로 거부한다. 평균·중앙값은 별도 행이다.
- 이전 저장 결과에 이 필드가 없으면 재계산 안내만 표시한다. 최신 통계를 과거 결과에 클라이언트에서 끼워 넣지 않는다. 새 결과는 기존 immutable result_json 저장 경로를 사용한다.
- 완료 검증: 등록/정규화/보류/범위·단계/원응답 및 산식 불변/저장 복원, 타입·변경 lint, 실제 결과 화면·모바일·stale 경로. 실계정/운영DB·배포는 별도.
