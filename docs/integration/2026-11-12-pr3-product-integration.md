## 통합 범위와 충돌 해결

- PR의 23개 경로를 공통 기준/현재 작업본/PR로 대조했다. 상품 카탈로그·정책·공시 원장은 PR 원문과 동일하다. 질문 어댑터·FE 브리지는 PR 코드와 같으며 파일 끝의 여분 빈 줄만 정리했다. 과거 ZIP을 사용하지 않았다.
- `planner.tsx`: 최신 로그인·상담 목록·버전 복원·세션 경쟁·저장 실패 처리를 유지하고 미리보기/저장 계산에 OUT-06을 요청한다. 요청 목록 변경을 현재 문서에도 반영해 정상 응답이 오래된 결과로 오인되지 않게 했다. 어댑터1.0 유지, v2 저장 경로를 다시 도입하지 않았다.
- `results.tsx`: 최신 부분 결과·오류·입력 버전·우선 행동과 미커밋 절세 안내를 보존했다. 상품 결과를 3번 투자구성 화면에 연결했고 4번 상품 화면에서도 재사용한다.
- `question_v12.py`: 공통 기준 대비 현재 변경이 없음을 확인하고 PR의 별도 상품 소비자 연결을 적용했다. 기존 재무 산식·OUT-05 예산은 변경하지 않는다.
- `investment-review.tsx`, `customer-flow.ts`: 기존 투자 질문을 재사용하고 D14 제외조건, D18 환율, D19 이해 자기응답, 필요한 NEW-12를 일반 화면에서 입력·수정한다. D19는 PR이 소비하는 기존 선택지 필드 `product_understanding`을 사용하며 객관식 상품 지식 검사가 완료됐다고 표시하지 않는다.
