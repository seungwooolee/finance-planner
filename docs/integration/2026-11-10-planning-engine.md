# 재무엔진 v1.0 통합 기록

사용자의 자율 구현·재검토 요청으로 기존 통합본 version4에서 작업했다. 새 app/planning 모듈·독립 사례·질문1.3-engine·인계 문서를 추가하고 현재 안내를 갱신했다. 원 앱 코드·정책 도구·fixture·v1.2 질문 원문·선택지와 프론트는 보존했다. 변경 파일·해시·기존본 비교는 루트 PACKAGE_MANIFEST.json에 기록한다.

실제 기능과 명령은 [실행 안내](../planning-engine-v1/README.md), 상태와 미실행 검사는 [검증 기록](../planning-engine-v1/verification.md)을 따른다. 저장 API/DB·화면·배포·Git 원격은 변경하지 않았다.
