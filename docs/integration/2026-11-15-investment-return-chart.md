# 선택한 투자안의 월별 자산 전망

## 자산군별 10년 가정 — 2026-11-16

최종 포트폴리오의 같은 차트에서 누적 납입 원금, 전체에 적용하는 직접 입력 가정, 자산군별 입력을 제공한다. 자산군별 입력은 사용자가 선택한 첫 계획 월의 신규 상품 배정액을 120개월 반복하는 별도 참고 경로다. 월말 납입이며 초기 평가액은 0원이다. 현금 대기자금, 기존 보유자산, 인출, 세금, 비용, 물가는 계산 범위에서 제외한다.

- 미리보기와 저장 결과의 기존 전망 요청은 `annual_rate_percent`를 받으며 기존 `연율 / 12` 산식을 쓴다. 자산군별 요청은 이 필드 대신 `asset_rates`와 `repeat_months: 120`을 보낸다. `asset_rates`의 코드 집합은 선택된 구성에서 금액이 양수인 상품 코드와 정확히 일치해야 한다.
- 자산군별 수익률은 원화 명목 연 유효복리율이다. 서버 Decimal에서 월 성장계수 `(1 + 연율)^(1/12)`를 구해 각 상품의 잔액에 적용하고 월말 납입액을 더한다. 이전 달 잔액과 상품별 잔액을 원 단위로 내림하지 않으며 표시용 월 합계에서 내림한다.
- 미국 대형주 원화 환산 참고 가정 `JPM_2027_US_LARGE_CAP_KRW`는 상품 360200의 원화 환노출·기초지수 확인 및 사용자 명시 선택이 필요하다. 2026-09-30 기준 연복리 7.50%와 USD/KRW 1,340.40에서 1,000.00에 이르는 말기 환율 가정을 사용한다. - 자산군별 응답은 `DION-ASSET-RETURN-ASSUMPTIONS-20261116-1.0`과 실제 사용한 `asset_rates`를 반환한다. 기존 선택·입력 해시 검증을 거친 뒤 응답하고 가정을 저장하지 않는다. 검산은 월 배정 239,700원을 120개월 반복했을 때 원금 28,764,000원, 합성 검사용 연 2%·5%·4% 평가액 33,779,540원, 미국주식 참고 가정에 나머지 두 자산군을 명시 0%로 둔 평가액 31,135,659원이다.

## 최초 구현

사용자 요청: 최종 포트폴리오에서 안정형·중립형·위험추구형 중 사용자가 반영한 투자안으로 투자할 경우의 월별 평가액·납입 원금·평가손익을 선으로 구분한다. 조사표의 과거 수익률과 비용은 미래 기대수익률 정책으로 등록하지 않았다. 이 기능에서 연 수익률은 사용자가 매번 명시하는 참고 가정이며 각 구성에 기본 수익률을 배정하지 않는다.

- 계산 범위: 새 투자계정 평가액 0원에서 시작. 선택한 재무안/구성의 OUT-06 상품별 실제 배정액을 합쳐 같은 월의 OUT-05 신규 후보금과 대조한다. 미배정액은 표에만 표시하고 수익을 적용하지 않는다. 기존 자산·외부 인출·비용·세금·물가·리밸런싱을 새로 가정하지 않는다. 기존 보유 금융자산의 수익 미반영 전망, 목표·배분 정책, 원응답, 채택/기록/운영 DB는 그대로다.
- 계산 관례: 기존 비교 가정 DION-PROPOSAL-REFERENCE-0.1의 명목 연율/12 및 월말 납입을 재사용한다. 이전 달 평가액에 월율을 적용한 뒤 이번 달 납입을 더한다. 내부 Decimal을 유지하고 각 표시 잔액만 원 단위 내림한다. 누적 평가손익은 표시 평가액−누적 납입, 월 평가손익은 이번/이전 표시 잔액 차−이번 납입이다. 실제 0과 배분을 확인하지 못한 상태를 구분한다.
- 기본은 계획에서 확인된 월별 배분이고 처음 확인할 수 없는 달에서 선을 끝낸다. 사용자가 1/3/5/10년의 ‘첫 달 배분 유지’를 명시 선택하면 원래 일정과 별개의 고정 납입 참고 경로를 제공한다. 이 기간의 상품 편입/계획 지속을 확인한 것은 아니다.
- HTTP의 기준은 investment_projection_api의 Pydantic/OpenAPI. 미리보기는 캡처 입력과 결과 해시를 다시 계산·대조한다. 저장 결과는 인증된 소유자, 동일 입력 해시·버전·run, 최신 선택 revision과 상품 정책을 서버에서 대조한다. 가정과 계산은 저장·채택되지 않고 요청 결과에만 반환된다. 화면은 선택한 구성/기준·가정이 일치할 때만 차트와 정확한 원 단위 표를 표시한다.

검증: 결정적 엔진/실제 API·임시 SQLite 9건(양수·0·음수, 가변 납입, 소수율 장기 독립 검산·원 단위 정수 경계, 실제 0·부분/배분 불일치, 미리보기 해시·유효성, 저장 결과 권한·경쟁 revision·스냅샷 보존)과 변경 Python Ruff, TypeScript, 변경 ESLint 통과. 연 4% 월율의 반복소수가 정확한 정수 원에서 1원 오차를 만들 수 있어 먼저 반올림하지 않고 정확한 Decimal 분자·분모로 누적한다.
