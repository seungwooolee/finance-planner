# 은퇴기 유산·상속 준비 RAG — 2026-11-15

## 자료 및 계약

- [검토된 Drive 원천 문서 6개](https://docs.google.com/spreadsheets/d/1c_sJg0cyRggEHOwFlb54TrSAnsfOv4PmTgnOBFMscMQ/edit#gid=754)에서 설명·조건·예외를 골라 data/rag/registry/corpus-inheritance-20261115.json에 등록했다. REVIEWED_SUMMARY로 표시하고 문서별 검토 기록에 Drive 링크, 응답 인용에 공식 법령 또는 정부24 링크를 연결했다.
- 기존 DION-RAG-CORPUS-1.0과 DION-SCHEME-EVIDENCE-1.0을 재사용한다. 기존 상품·세금 corpus는 동일하다. 상속 준비는 로그인 없는 공개 안내이므로 GET /api/fe/v1/inheritance-evidence/{item_id}가 유한한 주제 ID만 받는다. 사용자 답변·결과 ID·원 금액을 읽거나 전송할 필요가 없다.
- 응답은 서울의 조회일을 일반 안내 기준일로 표시한다. 2026-11-15에 검토된 요약을 사용하며 검토 유효 범위는 2026-12-31까지다. 개별 법령 시행본은 근거의 적용 조건에 별도 명시한다. 은퇴기 계산 기준일, 실제 상속개시일, 안내 조회일을 서로 대체하지 않는다.
- 해외 주소 관련 신고기한 질문은 열 수 있으나 등록 자료를 넣지 않아 출처·수치 없이 답변을 보류한다. 오래되거나 맞지 않는 자료도 기존 검색 필터로 보류한다.
- 결과의 상속 목표가 확인되는 현행 입력에서 유산·상속 준비 카드가 표시된다. 기존 모달의 남길 재산/받을 상속에서 고정 질문을 선택하고 근거와 조건을 펼쳐 확인한다. 이 조회는 외부 모델, 저장, 개인정보 전송과 별개이며 기존 엔진·채택·재무안 결과를 변경하지 않는다.

## 검증 범위

- 공개 API의 6개 주제, 출처 연결, 답변 보류, 검토 범위 밖 일자, 무관 주제 차단을 기존 상품 RAG 회귀와 함께 검사했다.
- 브라우저 대표 경로는 기존 공개 워크북 사례 Playwright 검사에 포함했다. 명시된 절차의 완료 및 남은 조건은 PR 본문에 기록한다.
- 실제 운영상담, 가구별 상속세 및 법적 상속분 판정, 전문가 검토는 이 설명 자료의 범위 밖이다.
