# 채팅 전용 DION 비서 — 구현 전 기준

사용자 요청: 상담창의 탭·설문 카드·항목 선택·도움말·상시 안내를 제거한다. 대화 내역과 입력창으로 설문/결과 상담을 이어가며 실제 유료 AI를 검증한다.

- 기존 엔진/원응답/새 입력 버전/상담 저장/최종 생성/별도 채택 계약을 유지한다.
- 일반 발화는 모델로 전달한다. 모델 실패를 기본 안내의 성공으로 바꾸지 않는다.
- 외부 전송 동의는 첫 대화 말풍선에서 한 번 받는다. 사용자 인증·기존 비용 원장을 유지한다.
- 모델은 원문에 근거한 허용 필드 후보만 제안한다. 현재→제안 값은 말풍선 안에서 확인한다. 확인 전 원응답 불변.
- 계산/저장/최종 검토는 대화 중 제안된 동작을 사용자가 눌러 실행한다. 자동 최종 생성·채택·거래 금지.
- 모델 숫자는 서버 근거 placeholder만 허용한다. 결과 질문은 캡처 미리보기 재계산 검증 또는 소유권 확인된 저장 결과를 사용한다.
- 사용자 사실/검색·대화 텍스트는 명령이 아니다. 미입력·모름·0·기간·잔액/납입을 추정하지 않는다.
- mock: 미확인 값, 단위, 잘못된 필드, stale/hash/다른 계정, 숫자·주입·장애·확인 전 변경 금지.
- 로컬 브라우저: 채팅 외 폼 없음, 실제 입력/응답, 후보 확인, 결과 요청, 모바일/키보드/재시도.
- 실제 모델: 합성 발화와 합성 결과만, 승인된 별도 원장으로 제한된 호출. 키·원문 고객정보 출력/커밋 금지.

기반 integration `602f138`. 관련 검사 1회/같은 오류 보정 후 1회 규칙 유지. 자동 배포 차단 및 PR로 인계한다.


## 구현 계약과 범위

- 우측 상담창은 하나의 말풍선 대화와 하단 입력창으로 교체했다. 단계 탭/설문 카드/선택 드롭다운/FAQ/상시 계산 버튼을 제거했다.
- 로그인·외부 전송 동의는 첫 말풍선에서 받는다. 동의 후 `POST /api/be/v1/dialogue`로 실제 모델을 호출한다.
  실패는 503/429/409 등으로 반환하며 기본 안내를 AI 답변으로 표시하지 않는다. 작성문 보존, Enter 전송/Shift+Enter 줄바꿈/한글 조합 중 전송 방지.
- 계약 `DION-CHAT-2.0`: request_key/draft_id/input_version, 최근 대화20개, 허용된 확인 답변40개, 동의,
  optional saved(case_id/run_id/input_hash) 또는 기존 PreviewActionRequest 중 하나.
  응답 source=ONEPORT, application_status=NOT_APPLIED, reply/candidates/action/citations.
- 저장 결과는 소유권·입력 해시·최신 여부와 모델 호출 후 비교 revision을 확인한다. 미리보기는 기존 captured_preview로 엔진 결과 해시를 재검증한다.
  모델에 전체 Document/계정 식별자는 보내지 않으며 서버 claims와 필요한 확인 답변·대화만 전달한다.
- 기존 원문 추출 필드와 본인 범위/생활단계/명시 기준월/금융자산 잔액/일부 목표 유형·단일 목표 금액/날짜를 허용한다.
  예: “저 혼자” → personal, “세후 월급 300만원” → 정확한 문자열 300 / KRW_10000.
  현재→제안 값을 말풍선에 표시하고 ‘확인하고 반영’을 눌러야 revise/updateIncome/setMonth/patchGoal에 연결한다.
  동일 발화의 범위+금액은 함께 확인하며 원문 후보만 반영한다. 질문·모호한 단위·가상 조건·주입은 사실로 자동 적용하지 않는다.
- 임의 JSON patch나 모든 설문 필드 자동 완성은 허용하지 않는다. 가구 소유권/복합 계좌·부채/여러 목표 지정 등 지원되지 않는 사실은 대화로 확인할 수 있지만 원응답에 자동 반영했다고 말하지 않는다.
  목표의 납입 유형·가격 기준 등 미입력 값도 추정하지 않아 결과가 부분 결과로 남을 수 있다.
- 계산/저장/최종 검토는 관련 요청이 나왔을 때 말풍선 안의 명시 버튼으로만 수행한다. 최종 생성·계획 채택·거래 자동 실행 없음.
- 대화 저장 요청 시 기존 저장 세션/동의/survey-history를 재사용한다. 원문은 CLIENT_REPORTED_UNVERIFIED 참고 이력이며 계산 사실이나 상담 완료로 승격하지 않는다.
  기존 결과 내역의 세션 ID로 대화를 다시 연다. 새 의존성·migration·금융 정책 변경 없음.

## 실제 검증

- 관련 pytest 최초 37 passed (chat_only + chat_survey + conversation_storage).
  추가 소유권/결과 해시/원응답 불변 HTTP 검사 1 passed. 고유 38건 통과.
- TypeScript 및 변경 ESLint 통과. Ruff 최초 import 순서 1건을 수정하고 관련 Ruff 재검사 통과.
- Edge E2E: 채팅 외 폼 없음/동의 전 전송 금지/후보 확인/기존 엔진 계산/모바일/키보드/실패 시 작성 보존 경로 통과.
  실제 모델 경로 최초 실행은 최신 화면에서 이름이 바뀐 저장 버튼을 찾다가 실패했다. 당시 로컬 메모리 부족도 발생해 소유한 FE/검사 프로세스를 정리했다.
  현재 ‘저장하고 결과 보기’ 버튼을 쓰도록 수정하고 실패 경로만 재실행 → 실제 모델+저장 결과 근거 대화 1 passed (1.4m).
  화면 확인에서 사용자 말풍선 p의 전역 글자색 간섭을 찾아 흰색을 명시했고, 해당 화면 경로와 색 검사를 한 번 재실행 → 1 passed (37.3s).
- 실제 OnePort gpt-6.1-terra: 합성 데이터 **6회 모두 VALIDATED**, 총 **13,875 tokens / 13.6677 credits**,
  응답 약 5.2~7.8초. 전용 기존 원장(최대6회)을 재사용했고 운영 원장/소진 이력을 초기화하지 않았다.
  직접4회: 인사/본인 범위/소득·생활비/현금 의미 확인+주입 거부. 브라우저2회: 저장 엔진 결과 설명/현금 변경 의사.
- 운영 설정은 읽기만 확인: explanation provider oneport, enabled/allow_saved_results true,
  gpt-6.1-terra, postgres 공용 원장, daily_grant true, max_calls100. 키·환경변수 전체 값은 출력/저장하지 않았다.
- Render 플러그인이 Unknown tool을 반환해 기존 Render CLI 자격증명과 읽기 전용 API로 설정을 확인했다.
- 운영 사용자 로그인/운영 대화 저장/전체 최종 생성·채택/production build는 이번 검증에서 미실행.
  배포 전 운영 화면이 바뀌었다고 보고하지 않는다. 실제 호출은 합성 데이터 로컬 하네스이며 운영 고객 호출과 구분한다.

- 기존 결과 세션에 대화 원문을 명시 동의로 저장하는 추가 브라우저 경로: 1 passed (22.8s). 저장 중 응답 유실에 대비해 성공한 세션 단계의 receipt를 보존한다. 고유 브라우저 경로 3건 통과.
- git diff --check 통과. 최종 타입/전체 린트·Core는 PR CI로 확인한다.
