# 결과 화면 공통 안내 정리 — 2026-11-15

- 재무안 비교의 ‘같은 점/다른 점’ 요약과 현금 등록 근거 펼침을 제거했다. 두 안의 그래프·비교표·차이 열과 금액 확인이 어려운 상태 표시는 유지한다.
- 결과 본문에서 질문·저장·AI 전송 동의 폼을 제거했다. 기존 기능은 우측 AI 상담의 ‘결과에 대해 질문’에서 열 수 있다. 선택안·버전과 질문을 연결하는 기존 흐름과 별도 전송 동의를 유지한다.
- 기본 결과 상단의 계산 기준 요약, 개발 검토 장문, 다음 버튼 왼쪽의 중복 제목을 제거했다. 오래된 결과·부분 결과·오류는 필요한 경우 한 번 안내하며, 원응답·계산·저장 버전은 유지한다. 검토 도구의 계산 기준 상세는 유지한다.
- Next typegen·TypeScript·변경 ESLint 통과. Edge 컴포넌트 검사 2건 최종 통과: 데스크톱·모바일 재무안 숫자/차이 열과 요약 제거, 정상 결과의 공통 문구 제거와 이전 결과 경고 유지. 이전 결과의 중복 재계산 버튼을 발견해 제거하고 해당 검사와 변경 lint만 다시 통과했다.
- 기존 상담/상품 E2E의 진입·표시 기대값을 새 화면에 맞췄다. 전체 앱의 로그인·저장·AI 전송·재진입 E2E 및 Build는 미실행이다.
- 엔진·BE·계약·운영 데이터 변경 없음. 작업 브랜치에서만 자동 배포를 차단하며, 원격 병합과 배포는 수행하지 않는다.
