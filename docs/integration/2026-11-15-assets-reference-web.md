# 자산 현황·최종 포트폴리오 참고 그래프 — 웹 구현

사용자 승인: 생활단계 참고 통계를 자산 현황에서 그래프로 제공하고 최종 포트폴리오에도 넣는다. 데스크톱 웹을 우선하며 좁은 화면의 가독성도 유지한다.

## 입력·출력과 비범위

- 저장된 `result.peer_reference`의 검토된 KRW 가구 자산·부채·순자산 행과 `user_value`만 표시한다. 수정 중인 질문·별도 통계 파일을 읽어 결과를 덮어쓰지 않는다.
- 총자산·부채·순자산을 공통 금액축으로 표시한다. 원문에 같은 출처/기간의 순자산 평균·중앙값이 있을 때만 전환한다. 생활단계로 집단을 자동 확정하지 않는다.
- 미확인/개인·가구 불일치 값은 0원으로 채우지 않는다. 실제 0원과 음수 순자산을 보존한다. BigInt 비율은 좌표에만 사용한다.
- 최종 화면의 비교는 현재 보유잔액이며 월 투자 후보금의 상품 배분·채택·실행·미래 잔액과 합치지 않는다. 두 화면은 동일 통계 스냅샷과 선택 상태를 사용한다.
- 참고용 상태를 유지한다. 차액·상대율·순위·추천·정책·BE/API/DB/법정 계산은 변경하지 않는다. 보류된 통계 수치는 활성화하지 않는다.

## 완료 조건·검증 계획

기존 질문→실제 preview 결과→자산 그래프→순자산 기준 전환→최종 화면의 같은 값, 데스크톱·좁은 화면, 이전 입력 상태를 관련 브라우저 검사로 확인한다. 별도 경계 검사는 0/null/음수/큰 정수·보류/범위 불일치·과거 필드 누락을 다룬다. FE 타입·변경 lint·공백 검사를 수행하며 전체 Core/Build/E2E는 이 표시 변경에 반복하지 않는다.

운영 데이터·유료 모델·배포는 범위 밖이다.

## 실제 검증과 제한

- `npm run typecheck`: 통과. 설치된 Next 16.4.3의 use-client/CSS 문서를 확인하고 기존 의존성을 재사용했다.
- 변경 TS/TSX 및 신규 E2E 파일 ESLint: 통과.
- `playwright test e2e/dion-asset-reference.spec.ts --grep 'asset display|chart coordinates' --workers=1 --reporter=line`: **2 passed (11.5s)**. 실제0/null/음수/큰 정수, 개인·가구 불일치, 보류/단위 불일치 비노출, 스냅샷 불변과 표시 좌표를 검사했다.
- 기존 React/TypeScript/Playwright로 실제 새 컴포넌트를 서버 없이 렌더링했다. 기존 BE `attach_peer_reference`와 공식 등록 통계를 사용하되 내 금액은 가상 fixture다. 자산/최종 각각 1440·1024·390px의 **6개 배치**에서 넘침 없음, 실제0/음수 막대, 개인 범위의 내 막대 미표시, 중앙값·stale 안내, 출처 펼침 통과. 실행 중인 Next/API 통합 E2E를 대체한 것으로 보고하지 않는다. 로컬 도구·fixture·캡처는 무시되는 `logs/`에만 있다.
- 실제 preview→범위 변경→재계산→최종→수정 후 이전 결과의 E2E 경로를 `frontend/e2e/dion-asset-reference.spec.ts`에 추가했지만 **미실행**이다. 로컬 FE/BE 개발 서버를 시작하는 `Start-Process` 명령이 자동 승인 검토에서 `blocked by policy`로 거절됐다. 동일 서버 시작을 다른 방식으로 재시도하지 않았다.
- 전체 Core/Build/E2E·실계정·운영 DB·유료 모델·배포: 미실행. 기존 금융 엔진·등록 통계·검토 정책·API 계약에는 변경이 없다.
