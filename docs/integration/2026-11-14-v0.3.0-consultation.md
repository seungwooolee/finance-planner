# v0.3.0 — 고양이 상담 패널

기준: `ee0726b` (PR #35 병합), `codex/release-v0.3.0`. v0.2.2의 진행 중 변경은 별도 checkout에 보존했다. v0.2.1~0.2.3의 완료를 전제하지 않고 사용자가 지정한 v0.3.0만 구현한다.

## 계약과 범위

- 단일 실행자가 FE 소비자와 기존 BE 경계를 함께 확인한다. 권위 계약은 `backend/app/be/consultation_api.py`, `app/consultation/contracts.py` 및 `service.py`, 기존 R1 explanation과 `/cases/{case_id}/plan`이다. 새 서버·새 금융 정책·권한 변경은 없다.
- 고양이 패널은 결과 내부 상담을 대체하는 단일 마운트다. 닫기/탭/질문 화면 이동은 세션과 작성 내용을 보존하고 case/token/run/input_version/hash/snapshot이 달라지면 분리한다. 저장하지 않은 임시 상담은 새로고침 후 복원을 약속하지 않는다.
- 서버의 base_input_version/hash, run/case를 검증한다. 오래된 입력은 변경 요청을 막으며, 사실 확인과 가상 비교는 기존 proposal/hash/expected_session_version 명시 확인을 사용한다. 상담은 진단·채택·거래를 실행하지 않는다.
- 재시도는 실패한 요청 본문과 request_key를 그대로 사용한다. 서버 응답 유실 후 중복 생성/확인을 방지한다. 렌더링·패널 열기만으로 상담 생성이나 유료 AI 호출을 하지 않는다.
- 채택 상태는 기존 plan GET을 패널을 열 때 읽고 조회 실패/미채택/같은 run/다른 run을 구분한다. 확인한 상태만 표시하고 상담 사실로 자동 입력하지 않는다.
- native dialog로 Escape/Tab 포커스/복귀를 제공하고 모바일은 시트로 표시한다. FAQ는 로그인 전에도 제공한다.
