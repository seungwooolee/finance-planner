# 생활단계 자산 참고와 절세 다음 행동

최초 기준은 통합 `b256a49`다. PR #106의 사전 사례 변경 `d5866d5` 위로 rebase하고 양쪽 개발 로그를 보존했다. 1·5번 결과 탭과 기존 미리보기/저장 계산의 부가 출력이 범위다.

- 자산은 결과에 사용한 LIFE-01 주 단계, 1인 가구 전체 여부의 명시 확인, 해당 결과의 검증된 원 단위 잔액을 사용한다. 연령·가구원수 교차 통계나 순위를 추정하지 않는다. [통계 원장 계약](../research/peer-reference/CONTRACT.md).
- `tax_guidance`는 `DION-TAX-FOLLOWUP-1.0`으로 제공한다. 결과의 입력버전과 입력 해시, 참고 귀속연도, 등록 자료 버전, 제도별 답변에 맞춘 이유·다음 확인·확인된 월 납입 입력액·근거를 싣는다. 저장 결과는 당시 부가 출력을 함께 보존한다. 기존 API, 원응답, 엔진 결과, 채택은 그대로다. 서버에 새로운 입력이나 세무정보를 보내지 않는다.
- 개인 납입과 계좌 보유는 기존 원응답의 확인된 본인 항목으로 한정한다. 가구 합산·월 세후소득·계좌 잔액을 연간 세액공제의 근거로 바꾸지 않는다. 1인 가구 비교 확인도 세무 범위에 전달하지 않는다. 세액·환급액은 `null`이다.
- TAX-01/02/03은 기존 정확 등록 검색을 사용한다. 귀속연도·효력일·검토일·관할·승인이 맞는 근거만 제공하고, 미등록·만료·손상 시에도 개인별 확인 항목은 남긴다. 검색 자료는 인용 가능한 공개 텍스트로 표시한다. 확인된 입력·근거의 합성에는 모델 호출을 쓰지 않는다.
- 완료 검사는 공식 셀과 원 단위 금액, 사회초년생/신혼기/은퇴기 힌트, 명시 확인의 효과와 보류, 실제 0과 미입력, 계좌 귀속·만료 시 fallback, 브라우저의 접근 가능한 조작을 포함한다.

공식 부록 통계표1~10의 N17/DL17은 29세 이하 총자산/순자산 중앙값 7,260만 원/5,000만 원이다. N10/N16/N21의 총자산 중앙값도 추가해 전체·39세 이하·60세 이상에 적용한다. 기존 원장 34행을 보존하고 5행을 덧붙였다. 평균은 직접 고를 수 있으며 중앙값 화면에는 부채 평균을 혼합하지 않는다.

로컬 Python 고유 38건 통과. 최종 변경에 직접 영향받은 원장·절세 14건과 Ruff를 한 번 확인했다. 표시 계약 5건과 실제 FastAPI·Next·Edge 1건 통과. 실제 가상 시트의 1,200만 원, 선택 취소, 390px 화면, 출처/보류, 5번 탭의 RAG 근거 및 Escape 후 버튼 복귀를 확인했다. 처음 브라우저 검사는 이전에 제거된 선호 조사 영역에 텍스트를 기대한 로케이터에서 실패했다. 화면과 공개 응답의 보류값 비노출을 검사하도록 보정한 해당 1건만 재검증했다.
