# v0.8.0 현재 결과 다음 행동 상담 — 2026-11-15

## 변경과 사용 흐름

결과 화면과 고양이 상담에서 현재 저장 결과를 두고 질문한다. 확인된 사실 최대 2개·관련 사유·다음 확인 1개를 표시하고 기존 질문/결과/상품 등록 근거로 이동한다. 양 재무안과 선택한 안정·중립·위험 추구 구성을 구분한다. 구성/입력/계정이 바뀌면 답변을 초기화하며 응답 전후 서버에서도 소유권과 버전을 검사한다.

`ecc:research-ops`의 출처·관찰/주장 분리와 `ecc:react-patterns`의 명시적인 상태 소유·요청 취소·접근성을 적용했다. 설치된 Next 16.4.3의 Client Component 문서를 확인했다. 상세 계약은 [result-action-contract](2026-11-15-result-action-contract.md)다.

AI는 동의한 질문 문장에서 지원 주제와 설명 길이를 선택한다. 실제 금액·문장·다음 행동은 같은 저장 결과에서 서버가 구성한다. 고객 원응답/금액을 모델 입력에 추가하지 않지만 질문에 직접 적은 내용은 전송된다. 동의하지 않으면 정해진 키워드에 따른 기본 안내를 사용한다. 모델 호출 실패도 기본 안내임을 표시한다. 자유형 금융 답변이나 임의 수치를 생성하는 기능은 아니다.

기존 OnePort 전송·설정·비용 원장·중복 방지를 재사용했다. 기존 R1/R2 API와 재무 계산/정책, 원응답, 계획 채택, 실제 금융 실행은 변경하지 않았다. 기능 2 자연어 입력 반영과 기능 3 월 코치는 이번 범위가 아니다.

## 실모델 상태와 남은 조건

`python -m tools.result_action_probe --live`는 고정 합성 질문 5건으로 ONEPORT 실제 응답만 통과로 인정한다. 개인정보/운영 고객 자료를 읽지 않는다. 준비 상태와 공유 전송의 모의 네트워크 계약·동의·영속 재시도 검사는 통과했다.

실제 키로 모델 목록/키 정보를 조회했지만 **게이트웨이 키의 일일 한도가 null**이어서 기존 `ONEPORT_GATEWAY_CAP_UNVERIFIED` 사전 검사에서 중단됐다. 생성 요청은 **NOT_SENT**이며 실모델 의미 분류 품질·토큰 사용/비용/지연은 **미검증**이다. 5건 중 3건은 사전 검사 제한, 나머지 2건은 분리된 테스트 원장의 예약 예산 제한으로 기본 안내를 반환했다. 이를 실모델 성공이나 비용 0원으로 계산하지 않는다. 실모델 검증에는 기존 계약에 맞는 게이트웨이 한도 설정이 필요하다. 현재 운영 설정이나 비용 방어를 변경하지 않았다.

운영 활성화에는 기존 OnePort 설정 및 saved-result 전송 허용이 필요하고 화면의 질문 전송 동의도 필요하다. `DION_RESULT_ACTION_PROVIDER` 미설정 시 기존 `DION_EXPLANATION_PROVIDER`를 따른다. 실제 모델 확인 전에는 기본 안내 구현·모의 연결 검증과 실사용 확인을 구분한다.
