# 채팅에서 최종 포트폴리오 검토까지

## 계약과 판정 기준

- DION-CHAT-2.0에 서버 결과 조회 경로와 저장 결과 상담 연결 정보를 추가한다. 인증, case/run/hash, 현행 선택 revision, 응답 검증 및 기존 요청 키를 재사용한다.
- 채팅의 원문 보관은 사용자가 동의한 기존 저장 상담 API를 쓴다. 참고 원문만 올려서는 상담 완료로 변경할 수 없다. 서버가 이 계정의 같은 결과·선택으로 처리한 채팅을 확인하고, 사용자가 상담 내용 확인을 수행한다.
- 변경 후보에서 원응답 식별자·기간·범위와 지원 필드를 확인한다. 원응답·기존 채택·월 기록은 변경 확인 전과 재계산 실패 시 보존한다. 미래 소득 반복 및 기존 미래 가정은 기존 명시 확인을 거친다. 같은 월 기준의 전후 엔진 금액과 명시 최종 생성을 확인한다.
- '현금을 더 남기고 싶어요'는 월 추가금과 보유 잔액 목표를 구분해 묻고 변경 후보를 만들지 않는다. 출처 없는 수치·주입·가정·보류 항목은 적용 금지다.
- 두 재무안은 동일 월의 신규 투자 후보·추가 현금·목표/보호/운영 배정에 연결한다. 공식 자료는 명시된 제도·상품 개념을 승인 원장에서 찾을 때만 연결한다. 유효하지 않은 근거는 보류한다.
- 단순 조회는 근거가 있을 때만 OnePort에 전송하지 않는다. 복합 질문은 OnePort 경로와 구조·근거 검증을 이용한다. 원문 없는 서버·공급자·검증 소요 시간을 기록한다.

## 검증과 인계

- 관련 Python 49건, 변경 Ruff·ESLint, TypeScript, 공백 검사 통과. 최초 비교 검사 두 건은 모의 조회에 원래 테이블의 입력 스냅샷 열을 포함하도록 수정해 재검증했다.
- Edge에서 모의 로그인과 모델, 임시 SQLite, 실제 엔진을 사용했다. 월 잔여액 조회의 공급자 소요 시간 0, 현금 의미 확인, 320만원 제안, 계산 결과에 저장 상담 연결, 확인 전 입력 불변, 두 버전 비교, 생성본의 반영 내역과 남은 질문을 확인했다. Windows Next 개발 캐시는 한 번 새로 시작했다.
- 채택 상태·이력은 서버 회귀 검사에서 보존됨을 확인했다. 운영 계정·DB, 실제 OnePort 변경 모델 호출, PDF, 배포 미실행.
- 채팅 증거는 기존 요청 영수증의 5분 유효기간에 연결된다. 이전 상담 원문은 계속 볼 수 있고, 새 선택이나 만료된 증거로 여는 검토는 현재 상담에서 한 번 이어서 확인한다.
