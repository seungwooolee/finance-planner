# 최종 포트폴리오 AI 종합 평가·추천

`POST /api/be/v1/cases/{case_id}/portfolio-reviews/{review_id}/assessment`는 소유권이 확인된 최종 생성본을 대상으로 한다. `explanation/final_assessment.py`의 Pydantic 모델이 요청·응답의 기준이다. 요청은 최종안 ID와 해시, 요청 키, 명시적인 모델 사용 여부를 보낸다. 서버는 생성본 해시와 당시 입력·결과 해시를 대조한다.

재무현황, 투자안, 절세, 연금, 유산·상속의 5개 평가를 보여준다. 각 평가에 저장 결과의 확인값, 다음 확인, 적용 가능한 공식 근거를 연결한다. 계산값을 다시 만들지 않는다. 미입력·0원, 조사 자료·개별 조건, 최종 생성·채택을 구분한다. 상속 공개 근거는 이전에 검토한 PR #103의 등록 파일을 동일한 내용으로 공유한다.

등록 근거 조회는 등록일·효력·검토기한·입력 기준일을 확인한다. 이전 최종안은 당시 결과로 읽고, 새 근거의 효력이나 현재 조건을 그때의 판단으로 소급하지 않는다. 확인되지 않은 개인별 세액·연금액·상속분·상품·비중은 표시하지 않는다.

고객이 OnePort 사용에 동의한 경우에만 승인된 평가 ID, 분류된 평가 신호, 공개 출처 식별자와 문맥 해시로 우선순위를 선택한다. 원응답·대화·자산·세액·상품명이나 금액·계좌 정보는 모델 입력에 포함하지 않는다. 모델 응답은 주어진 5개 ID를 중복 없이 정렬한 결과만 허용한다. 적자 또는 잔여액 미확인은 첫 필수 점검으로 남긴다. 모델 비활성·오류 때도 등록 근거와 기본 순서를 반환한다.

## 사전 판정 기준

1. 저장 최종안의 당시 재무안, 첫 계획 월 배분, 선택한 절세 시나리오, 확인한 연금·상속 입력만 표시한다. 위조 해시, 타인 사례, 생성 전 조회는 거부한다.
2. 정식 등록 문서만 인용한다. 기준일보다 뒤에 효력이 생긴 자료, 만료·손상·미확인 자료는 보류한다. 채택·월 기록·상담·원응답 쓰기 작업을 일으키지 않는다.
3. 금액·개인식별·고객 대화의 모델 payload 비노출, 명시 동의 전 호출 없음, 모델 응답의 미등록 ID·중복·적자 우선순위 우회 거부, 장애 시 기본 응답을 확인한다.
4. Edge에서 저장 결과의 상담·최종 생성본을 열고 키보드로 평가 열기, 5개 항목, 출처, 기존 최종안 표시를 확인한다.

## 실제 검사

관련 Python 31건에서 실제 저장/생성 API와 임시 SQLite, 등록 출처, 모델 대역을 사용했다. 사용자 소유권, 불일치 해시, 생성 전 조회, 미입력·0원, 효력일 이후 자료 보류와 승인된 우선순위, 공급자 장애를 확인했다. TypeScript와 변경 ESLint·Ruff 통과. Edge 대표 경로 1건에서 예상 국세 비교부터 서버 최종 생성, 기본 평가의 다섯 항목과 근거, 명시 동의, 모델 미설정 때 기본 평가를 확인했다.

관련 평가와 조치 문구는 서버에서 등록·확인한 범위만 표시한다. 외부 모델은 승인된 항목의 순서를 검토한다. 운영 계정, 유료 OnePort, 배포는 미실행이다.
