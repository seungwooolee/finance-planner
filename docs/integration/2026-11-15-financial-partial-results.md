# 재무현황 부분 결과와 기준월 검증

은퇴기 워크북 사례는 월 세후 소득 500만원, 생활비 300만원, 금융자산 신고액 5억원, 주택 전체 시세 10억원, 대출 잔액 1억원, 월 납부액 50만원, 월 저축·투자 10만원을 담고 있다. 가족 정보 동의, 소득·지출 기준월, 금융자산 상세 및 상환·납입의 계산 근거가 빠져 있다. 결과에 연결된 원응답을 읽어 입력 금액과 보완할 질문을 표시한다. 가족 범위 합계·순자산·월 잔여금의 계산 보류는 유지한다.

재무현황은 한쪽 증빙이 부족해도 계산 근거가 확보된 전체 채무 또는 전체 자산을 표시한다. 금융자산 내역이 누락됐거나 일부만 확인되면 자산 범위를 일부로 처리한다. 순자산과 자산 구성에는 전체 합계가 필요하다. 부동산·보증금 표시 제한 중에도 계산된 채무를 확인할 수 있다.

소득·지출의 기준기간 밖에 있는 대출 납부액은 해당 기간의 월 잔여금에 쓰지 않는다. 확인된 생활비와 채무 잔액은 계속 표시한다. 직접 입력은 소득·지출 기준월을 질문 화면에서 선택한다. 소득 300만원, 생활비 160만원, 채무 없음 사례의 상환 후 잔여금은 140만원이다. 기존 저축·투자가 미확인이면 저축·투자 반영 후 잔여금에는 확인 대기를 표시한다.

## 검증

로컬 Edge와 실제 미리보기 API로 `dion-workbook-demo.spec.ts`의 은퇴기 전환과 직접 입력 시나리오 2건을 확인했다. 표시된 원응답, 미확인 순자산, 채무 0원, 기준월 보완 전후의 월 잔여금을 검증했다. TypeScript, 변경 UI ESLint, 백엔드 Ruff와 pip check를 통과했다. 상환 기준월과 부분 자산 집계의 고정 정답은 `backend/tests/planning/test_result_delivery.py`에 추가했다.
