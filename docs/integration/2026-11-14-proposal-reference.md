## AI 상담(R2)·해설(R1) 보완

- R2 의도 규칙: 일상 질문 20개 중 12개가 '어떤 도움을 먼저 받을지 선택'으로 빠지던 문제를 보완했다. "가정"(가족) 오인을 막고, 개별 상품 추천·보험·상환 순서 질문은 지원 범위 밖 안내로 답한다. 정책 버전은 올리지 않았다(저장 세션 호환).
- OnePort 활성 시 질문형 문장도 유료 추출 호출로 보내 서버 근거 검사에서 422(MODEL_PROPOSAL_INVALID)가 나던 문제를 수정했다. 서버가 근거화할 수 있는 진술 문장만 호출한다.
- R2에서 결과 설명 의도면 "결과 해설 바로 열기" 버튼을 보여준다.
- R1 해설: 409/422/429/5xx를 구분한 안내, 429·502·503·504는 같은 요청 키로 3초 뒤 1회 재시도(20초 기한 유지).
