## 동작과 경계

- `asset-reference.ts`의 공용 표시 계약 `DION-ASSET-REFERENCE-VIEW-1.1`을 자산 현황과 포트폴리오에서 같이 사용한다. API의 `DION-PEER-REFERENCE-1.0`/REFERENCE_ONLY 계약, 차액·상대율 null을 유지한다.
- 각 지표의 제공/부재/보류/자료 확인 필요와 내 금액의 가구범위 불일치/미확인을 구분한다. 자료가 여러 출처·연도로 중복되면 첫 행을 임의 선택하지 않고 보류한다. 평균/중앙값의 출처·기간이 다르면 혼합 전환하지 않는다.
- 선택 출처 ANSWER_HINT/EXPLICIT, 고객 집단 소속 UNCONFIRMED, 비교 REFERENCE_ONLY를 구분한다. 선택은 집단 소속 판정이 아니며 생활단계 힌트가 없는 경우 전체 가구로 대체하지 않는다.
- 선택 집단의 제목·제공 지표·공통 금액축의 항목별 막대·정확한 수치 표·출처가 함께 바뀐다. 이전 범주형 선 그래프는 변화/추세로 읽힐 수 있어 이 비교 패널만 가로 막대로 변경했다. 미래 시계열 MoneyLineChart는 유지했다.
- 최초 화면/포트폴리오의 기존 공유 상태를 `useAssetReferenceSelection`으로 옮겨 같은 훅으로 검증한다. 같은 결과에서는 양방향 공유, sourceSignature가 다른 결과에서는 초기화한다. DB 영속 저장 기능을 새로 만들지 않았으며 원응답·재무 결과·배분·채택·거래를 변경하지 않는다.
- 과거 저장 결과는 당시 snapshot과 제공 지표를 그대로 보여준다. 새 자료는 새 계산에만 붙는다. 0/null·음수·정확한 원 문자열은 보존하며 BigInt는 차트 좌표에만 사용한다.
