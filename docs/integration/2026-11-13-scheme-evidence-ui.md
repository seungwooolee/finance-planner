# 결과 상담 화면과 첫 실제 근거 등록 상태

## 7단계 화면 연결

저장 결과의 기존 해설, 짧게/자세히, 근거 펼치기를 유지한다. 해설에서 결과 상담으로 이동할 수 있다. 상담은 추가 질문, 기존 답변과의 충돌, 가상 조건 확인, 비교 조건 확인, 비교 결과를 구분한다. R3 비교 계산은 기존 두 확인 계약을 거치며 저장 진단에 자동 반영하지 않는다.

`GET /api/be/v1/cases/{case_id}/agent-sessions/{sid}/scheme-evidence?expected_session_version=...`는 상담과 run을 확인하고 현재 검색 검증을 통과하는 제도·귀속연도만 목록으로 돌려준다. 승인된 목록의 표시 이름은 corpus의 선택 필드 `item_labels`에서 온다. 사용자가 연도를 선택하면 같은 경로의 POST로 등록 근거를 조회한다. 목록 또는 답변이 비었거나 실패하면 저장 결과를 계속 볼 수 있다. 응답은 해당 상담·run·버전·제도·연도에 연결하며, 해당 화면을 벗어나면 진행 중 요청을 취소한다.

제도 화면에는 일반 안내, 개인 적용 확인, 개인 세액 계산의 범위를 각각 표시한다. 현재 개인 적용 확인과 세액 계산은 지원 밖이며 관련 상세 정보를 수집하지 않는다. 원문 설명에 적용 조건과 예외를 표시한다. 근거 펼치기에는 출처·공식 링크·문서 위치·버전·적용 귀속연도·검토 승인일·재검토 기한을 표시한다.

## 8단계 자료 확인 및 보류

2026-11-13에 공유 조사표의 세금 조건, RAG 근거관리, 답변질문연결, 검증사례 및 개발준비 탭을 읽기 전용으로 확인했다. 세금 조건 40행의 조사 결과는 0행이다. 근거관리의 8행은 모두 미조사이며 실제 확인 URL·귀속연도·검토자는 0행이다. 매핑 8행은 모두 검토가 필요하며, 검증 사례 20건의 실제 source/chunk 연결은 0건이다. 시작 링크는 조사할 위치로만 사용한다. [팀 조사표](https://docs.google.com/spreadsheets/d/1Ds5Az86yVi9qBf_uXiGnb2_oBPwmh4ILzSjRd-FYV4I/edit#gid=161120605)

등록을 재개하는 데 필요한 자료는 다음과 같다.

1. 팀이 조사한 제도 하나와 확인된 귀속연도 하나. 실제 확인 URL, 원문 보존본, 조항·표·페이지 위치, 버전·지문, 확인일과 효력 시작/종료.
2. 별도의 정책 검토 승인 기록. 승인자·참조·승인일·재검토 기한, 허용 주장, 필수 조건 및 예외, 상충 처리와 금지 결론.
3. 대상·기간·측정기준과 기존 질문 정의 버전을 맞춘 재사용 및 추가 질문 승인. 예를 들어 월세 세액공제의 `MAP-04`에서 실제 등록 후보인 `N02.housing_type`(1.2)는 주거 유형만 확인한다. `TAX-01.tax_contexts`와 `TAX-02.tax_contexts[].income_details`는 정의 1.2에 있으나 현재 11개 R2 상담 필드에는 없다. 월 세후소득 `F03`(1.2)과 월 지출 `F04`(1.2.1)를 연간 세무소득이나 임대료 지급 증빙으로 쓰지 않는다. 이 확인은 매핑 후보 점검이며 실행 매핑을 승인한 것이 아니다.
4. 승인된 source/chunk와 기대 주장·예외·금지 결론을 연결한 검증 사례. `QA-01`의 정상 인용, `QA-02`의 연도 확인, `QA-03`의 월소득과 연간 세무소득 구분, `QA-04`의 타연도 배제, `QA-05`의 근거 없음부터 선택 제도에 연결한다.

이 상태에서는 실제 제도·연도, source/chunk, 허용 주장과 추가 질문을 확정할 수 없다. 운영 corpus와 조사표는 변경하지 않았다. 합성 시험 제도는 브라우저 테스트 하네스의 명시 옵션에서만 표시된다.
