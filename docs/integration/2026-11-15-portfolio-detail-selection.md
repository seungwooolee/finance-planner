## 동작과 경계

- 생활 안정 우선/투자 여력 확대의 각 재무안에서 안정·중립·위험추구 구성마다 `상세 보기 · 상품·금액·위험`을 펼친다. 각 월의 후보금, 검토 배분액, 미배분 잔액, 상품별 금액·비중, 확인된 위험등급·총보수·환노출·공식 자료, 서버 사유와 내부 하락 시나리오를 표시한다.
- 열어보기는 선택/저장 요청을 하지 않는다. `이 구성으로 반영하고 포트폴리오 확인`은 기존 comparison.choose 성공 후 포트폴리오 검토안 화면으로 이동한다. 기존 카드 선택→상품·비중 확인도 유지하며 상품 화면에 포트폴리오 바로가기를 추가했다.
- 저장 성공 여부, revision/원응답 hash/정책 버전, 중복 선택, 저장 실패 시 기존 선택 유지, preview와 저장 run의 구분은 기존 hook/API를 그대로 사용한다. 선택은 상담용 검토안이며 최종 생성·채택·금융 거래가 아니다.
- 첨부 화면은 이전 계산의 selectable 누락으로 반영이 막힌 상태다. 과거 세부 내역은 읽을 수 있으나 선택 제한을 해제하지 않는다. 같은 화면의 `현재 입력으로 다시 계산`으로 최신 결과를 요청한다. 재계산은 사용자 클릭 시만 실행하고 기준일·금융 정책을 자동 변경하지 않는다. 재계산 후에도 조건에 따라 선택이 보류될 수 있다.
- 실제 0/미확인, 월별 금액과 P1~P5 원응답을 보존한다. 엔진 금액을 다시 계산하지 않고 비중 표시만 기존 BigInt 도우미를 재사용한다. 분모가 0/미확인이면 비중을 확인 대기로 표시한다.
- 이번 변경에 BE/엔진/DB/금융 정책/상품 추천 활성화는 없다. 수익률·위험의 금융 타당성 검증을 새로 수행한 작업이 아니다.
