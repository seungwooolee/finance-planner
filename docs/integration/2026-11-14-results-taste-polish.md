# 결과 화면 디자인 보완

## 방향과 범위

- 목적: 재무현황의 핵심 금액을 먼저 읽고, 같은 결과의 자산 구성·현금흐름·상품 검토·절세 안내를 확인한다. 기존 숫자·상태·저장·선택·질문 이동을 유지한다.
- 방향: 차분한 재무 보고서. 흰색 카드와 중성 배경, 기존 DION 남색을 핵심 숫자·현재 위치·선택에 사용한다. 고양이·기존 차트의 의미별 색상은 보존한다.
- 관찰: 기존 화면은 보라색 면과 중첩 박스가 많고 표와 그래프가 세로로 길었다. 자산 범례의 긴 명칭·출처와 모바일 탐색은 줄바꿈·터치 영역을 유지한다.
- 대상: 1440×900 데스크톱과 390×844 모바일. 결과 화면만 적용하며 시작·질문·인증 화면은 별도 디자인 범위다.
- `/taste` 설치본은 영상용이다. 시각 방향의 일관성·강조 절제 원칙을 참고하고, UI 구현에는 설치된 `frontend-design-direction`의 해당 부분을 적용한다. 영상·이미지 생성·새 패키지·금융 정책 변경은 없다.

## 상태와 확인 범위

- 계산 완료: 핵심 금액→현황/자산→현금흐름 순서로 읽고 기존 결과/근거와 대조한다.
- 실제 0·부분자료: 기존 안내와 질문 수정 버튼을 보존한다. 분류가 없을 때 차트를 만들지 않는다.
- 오래된 결과·오류: 기존 상태 색과 설명·재계산 동작을 보존한다. 성공 상태와 같은 색으로 덮지 않는다.
- 로딩·권한: 새 요청·인증·비활성 정책을 추가하지 않는다. 운영 계정/DB/AI의 상태는 이번 디자인 검사로 검증하지 않는다.
