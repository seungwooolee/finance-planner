## 129.9와 은퇴기 검산

사회초년생 원응답의 단위는 만원, 엔진의 금액은 정수 원 문자열이다.

```text
소득                         3,000,000원 (300만원)
입력 전체출금                1,901,000원 (190.1만원)
전체출금 포함 상환              101,000원 (원금100,000 + 이자1,000 + 비용0)
전체출금 포함 저축·투자          200,000원
정규화 생활비 = 1,901,000 - 101,000 - 200,000 = 1,600,000원
상환 후 = 3,000,000 - 1,600,000 - 101,000 = 1,299,000원 (129.9만원)
기존 납입 후 = 1,299,000 - 200,000 = 1,099,000원 (109.9만원)
```

129.9는 기존 저축·투자를 빼기 전 금액이다. 계산을 바꾸지 않고 ‘대출 상환 후 남는 돈’으로 표시했다. ‘저축·투자까지 반영하고 남는 돈’과 구분하며 표·그래프는 같은 엔진 표시 행을 사용한다. 참고 예시 300−150−30−50=70은 앱 결과에 넣지 않았다.

은퇴기 사례는 F06 현금성 자산1,500만원, 채무 없음, 분석 범위 내 부동산 보유 없음으로 입력돼 있다. 총자산1,500만원은 이 사례의 현금성 금융자산 합계와 일치한다. 거주 형태만으로 부동산 잔액을 생성하지 않았다.
