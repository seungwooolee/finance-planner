# 담당 밖 파일에 대한 제안

이번 변경은 docs/design/2026-11-10과 docs/submission/2026-11-10 안에 한정했다. 기존 BE·엔진·질문·Next 앱·통합 manifest·총괄 문서는 수정하지 않았다.

- BE: 데모의 payload 보관·명시 상태 매핑·결과 스냅샷 연결은 참고 구현이다. H01~H12 접수 후 운영 계약으로 검토한다. 1.2.1→1.3-engine 이관, 실제 인증, 원자적 여러 카드 저장, 결과저장 내구성, 운영 DB/API가 필요하다. private `_version` 호출도 운영 연결 시 공개 계약으로 대체한다.
- 엔진: 상한 전용 필드·권장액 필드의 제공 범위, 사용자 언어의 결과별 부족 필드·다음 행동을 계약으로 확정해 인계한다. 화면이 상한/권장액을 임의 계산하지 않게 한다. 일별 지급 가능성과 적합성은 미완료 유지한다.
- 질문: 질문 패치1.2.1의 의미·비용·잔액 기준시점과1.3-engine 바인딩을 BE와 대조한다. 실제 전체55 폼·세금/연금/상속 중첩필드의 가시 부담은 후속 실제 UI에서 측정한다. 이번6/4 컨트롤 측정을 전체 질문 부담 실측으로 확대하지 않는다.
- 총괄: 변경 ZIP을 v5 이후 통합 시 단일 기준 manifest를 다시 생성하고 해당 전체 앱의 Core·Build·E2E를 실행한다. 공식 참가자 파일명·B안 사례 선택·과거 AI도구 이력·전원 서명은 최종 확인한다. 참가자 검토 전 AI의 자동 검사 기록을 본인의 직접 검증 완료로 쓰지 않는다.
- 제출: 서명은 참가자가 직접 하며 실제 접수·외부 공개는 수행하지 않았다. 파일명과 공식 빈 서명 양식은 SUBMISSION_READINESS.md를 따른다.
