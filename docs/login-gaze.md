# 로그인 화면과 고양이 시선 반응

## 승인 범위

2026-11-01: 사용자가 제공한 2열 로그인 화면을 참고하여 `/login` 화면을 만들고, 누끼 고양이가 커서를 쳐다보도록 한다. 기존 상단 걷기 고양이와 함께 진행한다.

## 완료 조건

- 왼쪽 고양이/소개, 오른쪽 입력 폼의 2열 구성. 모바일에서는 세로로 배치한다.
- 실제 누끼 사진의 얼굴·체형·무늬를 유지한다. Canvas에서 홍채 영역만 제한적으로 다시 그려 눈동자가 커서를 따라간다.
- 비밀번호에 포커스가 있거나 비밀번호 보기가 켜져 있으면 시선을 반대편으로 돌린다. 시선 로직은 비밀번호 내용에 접근하지 않는다.
- 터치에서는 중립 시선, 동작 줄이기에서는 정적인 시선. 탭 숨김/화면 밖/컴포넌트 해제 시 애니메이션과 이벤트를 정리한다.
- 고양이 이미지 오류가 로그인 화면이나 체험 동선을 막지 않는다.
- 기존 헤더에서 `/login`으로 이동하며, 로그인 화면의 `로그인 없이 체험하기`가 기존 `/` 계산기로 연결된다.

## 인증 경계

현재 저장소에는 회원·세션·계정 인증 서비스가 없다. 이번 범위는 로그인 UI와 캐릭터 인터랙션이다. 실제 로그인인 것처럼 임의 성공 처리하거나 클라이언트 저장값으로 접근을 보호하지 않는다. 계정 로그인 준비 중임을 화면에 표시하며 로그인 제출은 비활성화한다. 폼은 네트워크로 자격 증명을 전송하거나 브라우저 저장소에 보관하지 않는다. 인증 서비스 선택·회원가입·소셜 로그인·서버 세션은 별도 기능이다.

## 검증

포인터 방향별 눈동자 이동, 비밀번호 포커스/보기 전환, 키보드 접근, 모바일 넘침, 이미지 알파, reduced-motion, 실제 체험 링크를 확인한다. 실행한 검사와 환경 제한은 개발 로그에 구분해 기록한다.
