# 절세 계산 계약 0.1 — TAX-01 연금계좌 세액공제 (초안, 엔진 미착수)

로드맵 4단계 조건: **계약과 정답 데이터를 먼저 고정하고, 승인 후 엔진을 만든다.** 이 문서와 [`data/tax-engine/tax01-golden-0.1.json`](../../data/tax-engine/tax01-golden-0.1.json)이 그 첫 묶음이다. 아직 계산 코드는 없다.

## 범위

| 포함 | 제외 (입력되면 `UNSUPPORTED_SCOPE`) |
| --- | --- |
| 2026 귀속, 거주자, 국세 세액공제액 | 지방소득세, 환급액·결정세액 |
| 연금저축 600만원 / 합산 900만원 한도 | ISA 만기 전환 추가한도(TAX-03) |
| 공제율 15% / 12% 분기 | 미공제 납입액 이후 전환, 연금 수령 과세(TAX-08) |
| 이연 퇴직소득·계좌 이전액 제외 | 부부·부양가족 합산 |
| 산출세액 한도(제61조 제3항) | |

## 입력 (정수 원, 모르면 `null`)

`tax_year`, `resident`, `income_type`(`EARNED_ONLY`·`COMPREHENSIVE`), `total_salary_krw`(근로소득만인 경우), `comprehensive_income_krw`(근로 외 소득이 있는 경우), `pension_savings_paid_krw`, `retirement_account_paid_krw`(IRP·DC 본인 추가부담), `excluded_paid_krw`·`excluded_from`(이연 퇴직소득·계약 이전액), `computed_tax_krw`(종합소득산출세액), `other_credits_krw`(다른 감면·공제 합계).

`null`을 0이나 낮은 소득으로 바꾸지 않는다. 월 순소득으로 총급여를 추정하지 않는다.

## 규칙

1. `연금저축 인정액 = min(연금저축 납입 − 해당 제외액, 6,000,000)`
2. `공제 대상액 = min(연금저축 인정액 + 퇴직연금 납입 − 해당 제외액, 9,000,000)`
3. 공제율: 근로소득만 있고 총급여 ≤ 55,000,000이면 15%, 근로 외 소득이 있고 종합소득금액 ≤ 45,000,000이면 15%, 그 외 12%
4. `한도 전 공제액 = 공제 대상액 × 공제율`
5. `적용 공제액 = min(한도 전 공제액, max(0, 산출세액 − 다른 감면·공제))`

## 출력 상태

`CALCULATED` · `NEEDS_INPUT`(누락 필드 목록) · `UNSUPPORTED_TAX_YEAR` · `NOT_APPLICABLE`(비거주자) · `UNSUPPORTED_SCOPE`. 어떤 상태든 환급 보장 문구를 내지 않고, 결과는 R2-b 근거(TAX-01 등록 원문)와 함께 표시한다.

## 결정 (2026-11-13, 사용자 위임)

- **원 단위**: 공제액은 원 미만 절사. 10원 미만 끝수 처리(국고금 관리법 제47조)는 납부·환급 단계의 규칙이라 이 계약 범위 밖이다. 세액공제 계산 단계의 원 미만 절사 근거 조문은 외부 대조 때 함께 확인한다.
- **적용 순서**: 제61조 제3항 문언대로 다른 감면·공제를 먼저 반영하고, 연금계좌세액공제는 남은 산출세액 한도에서 적용한다(G07).
- **정답 검토**: 엔진과 별개인 산술 검산 테스트(`tests/planning/test_tax01_golden.py`)로 10건이 계약 규칙과 일치함을 확인했다(`INTERNAL_ARITHMETIC_CHECKED`). 외부 대조는 RAG 조사 팀원이 국세청 연말정산 모의계산으로 하고, 끝나면 `APPROVED`로 바꾼 뒤 엔진을 시작한다.
- 이후 제도(TAX-02~14)는 같은 형식으로 계약·정답을 하나씩 추가한다.
