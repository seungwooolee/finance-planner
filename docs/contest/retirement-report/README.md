# 은퇴·상속 심사용 웹 시연

`DION-RETIREMENT-REPORT-1.1`은 작성팀 IFPK AFPK 영플래너 챌린지 초안의 은퇴기 사례와 금리 충격 그림을 기준으로 한다. 여섯 보유 상품, 대출 1억원·월 이자 50만원, 상품별 수익률과 민감도는 사례의 입력이다. 시장에서 확인한 현재 금리나 상품별 예상 수익률로 사용하지 않는다. 최종 포트폴리오에서 총자산과 금융자산 차트를 보고서 기준액과 선택안 적용 후 금액으로 전환할 수 있다.

- 보유자산 비교에서 머니마켓 3,000만원 중 비상자금 1,000만원을 분리하고 이 돈의 수익을 0원으로 가정한다. 전액 상환 시 국고채 1억원을 추가로 현금화한다. 상환·거래비용·세금은 미반영이다.
- 월별 계산은 기존 엑셀 시연의 가정과 `OUT-04`~`OUT-06`을 사용한다. 대출을 유지하고 주거 정비비 60만원을 준비하는 예시다. 보고서 운용안의 연 수익과 상환 가정을 월 소득·채무에 더하지 않는다.
- 상품 추천 시연 v5는 12월 시작 전에 머니마켓에서 50만원을 추가 현금화해 시연의 비상자금 1,050만원을 확보했다고 가정한다. 운영자금 350만원과 총 금융자산 5억원을 유지한다. 월별 신규 투자 후보금은 12월과 1월 모두 두 안에서 각각 55만원·88만원이다. 보고서의 비상자금은 1,000만원이며 원본 투자 조건 v3의 12월 신규 후보는 0원이다.
- 가상 월별 재무계획 저장은 본인 권한의 별도 테스트 사례를 생성한다. 저장 뒤 월별 후보를 명시 채택할 수 있고, 채택한 뒤 첫 계획 월의 가상 금액을 기록할 수 있다. 기록은 저장 당시의 채택 ID에 연결된다. 첫 계획 월을 열 수 있는 시점과 월 마감 조건은 기존 서버 규칙을 사용한다.

## 재현

루트에서 `python docs/contest/retirement-report/build_snapshot.py`로 스냅샷 대사와 초안의 충격 손실률 재현을 확인한다. 소스 가정에 승인된 수정이 생기면 같은 스크립트에 `--write`를 붙여 JSON을 갱신한다.

브라우저 여정은 `frontend/e2e/dion-retirement-report.spec.ts`에 있다. 임시 SQLite 하네스 `backend/tests/fe_http_harness.py`에 `--test-clock 2027-01-05T11:00:00+09:00`을 적용한다. 새해 첫 주 시점의 가상 기록 검사를 위한 테스트 설정이다.
