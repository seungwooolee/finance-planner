# 이번 달 기록·점검 — 확정 요구 정리

기존재방문대시보드에서‘이번달기록하기’‘지금미리지출기록하기’‘점검기록’이같은기록흐름으로연결된다. dion의인디고/라벤더·흰카드·고양이캐릭터를이어받는다.

- 상단:기록월/집계기간(1일~기준일)/중간기록·월말마감/채택계획명·버전·적용일/마지막저장/직접입력출처. 초안을비교계획으로쓰지않는다. 계획없어도기록가능,계획선택안내.
- 월합계입력:소득300,생활150,대출20,목표20,기존투자40,신규투자30,비상20,추가현금20만원예시. 소득300과배분300을서로더해600이라고하지않는다.
- 실제입력기본빈칸. 0=실행없음/빈칸=미입력. 계획을실제로복사하지않는다. 만원입력→정수원정확환산. 숫자키패드·라벨·단위·오류표시.
- 생활비상세식비/주거/교통/기타는선택펼침. 합계와세부중복집계금지.
- 적립·투자·저축은자산간이동이며생활비와구분. 납입액은수익/평가손익이아님. 신규일시400·이미분리한주거400은월소득배분에합산하지않고별도기록.
- 입력한것만합산하고부분기록배지. 중간누계를월전체성공/실패로단정하지않음. 소득초과배정은저장을막지않고기존잔액/추가수입/입력오류확인. 자금출처를소득에중복더하지않음.
- 할일예정/진행/완료/보류+이유. 등록완료≠실제납입,잔액확인≠대출상환. 체크로금액자동입력금지. 3/4완료=75%.
- 소득/예상외지출/부채/목표/투자생각/변화없음. 변화는새초안검토,원채택자동변경금지.
- 임시저장/점검완료. 월말핵심누락보완안내·실행없으면0. 실패시입력유지+재시도. 저장후기록월/기간/완료수/실제배분/다음점검. 마감본수정가능하되이력보존.
- 재방문시마지막저장·이어하기·지난월조회. 월중계획변경의귀속기간/버전기준은상세명세로확정할필요가있음.
- 최초무기록/중간/월말완료/초과배정/저장실패상태. PC비교표,모바일세로카드·고정저장버튼. 보조상세는접음.
- 계좌연동·송금·매매완료가짜표시,근거없는확률·원금보증금지. 냥코치는실제기록근거로설명.
