# 화면 자료의 역할

- Stitch통합ZIP:32HTML/25PNG의디자인내보내기. 새재방문/월간기록추가는그ZIP안에없다. 기본버튼href=#등으로실제앱이아니다.
- Returning Dashboard ORIGINAL:사용자첨부HTML. 원본그대로이며진행률3/4=67%(75%가맞음),실계좌연동확인·95%확률·운영엔진버전등미검증문구가있다. 채택계획/초안분리는참고하고내용을실제상태에맞게수정해야한다.
- Monthly Checkin PROTOTYPE:독립단일HTML. localStorage만사용. 현재적용계획은예시이며실제DB·월중계획분할·기기동기화가없다. 입력/저장/월말화면흐름참고용이다. 가로배분막대는기존명세와충돌하므로수정필요.
- 고객결과정식계약은별도07_REFERENCE_SNAPSHOTS/frontend의5+5뷰명세를함께읽는다.

이번ZIP은디자인작업을크게뒤엎으라는지시가아니다. 핵심결과화면은충분하며입력·예외·전체보유비교·실적·모바일상태와데이터연결을마무리한다.
