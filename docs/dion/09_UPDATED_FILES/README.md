## 현재 서비스 방향

dion은 고객의 재무진단을 바탕으로 투자 포트폴리오와 대표 상품을 이해·검토하고, 이번 달 실행과 사후 점검으로 이어가도록 돕는 투자 중심의 쉽고 빠른 재무 컨설팅 서비스다. 고객을 직장인이나 사회초년생으로만 제한하지 않는다. 여섯 생애 구분을 참고하고 고객 목표를 따로 확인한다.

- 6단계: 관계·범위 안내 → 정보·목표 → 분석·평가 → 제안·선택 → 실행 지원 → 실적·상황 점검.
- 재무계획2안: 생활 안정 우선 / 투자 여력 확대.
- 자기보고 투자성향5단계와 투자구성3유형은 다른 개념이다. 적합한 기본안 하나와 허용되는 대안을 구분한다.
- 전체 보유현황을 고려하고 신규 일시금·향후 납입으로 먼저 조정한다. 필요한 경우에만 기존 금융자산 변경을 검토한다. 부동산 기본 유지.
- 분석 대상은 예적금·주식·채권·ETF·펀드 등 금융자산. 보험·연금 제외 결정은 유지한다. 다만 최신 질문 원문에는 연금저축·IRP·파생 검토가 남아 있어 **범위 검토대기**로 표시한다. 원문 보존은 해당 기능의 운영 승인이나 구현을 뜻하지 않는다. 실제로 받는 세후소득의 원천과 연금상품 추천은 구분한다.
- 해외 기초자산 노출은 국내 상장 ETF·국내 판매 인덱스펀드 범위를 우선 검토한다. 개별 후보 지원 범위는 DEC-07 등 검토 사항을 해소한 뒤 확정한다.

## 질문·미리보기의 동작 범위

- 질문은행40개는 모든 고객의 필수40문항이라는 뜻이 아니다. 빠른진단은 기본11개(필수10·선택1)＋부동산·채무 해당자 상세0~2개, 정밀진단은 직접 진입한다. 기존 응답을 재사용하며 반복 설문을 강요하지 않는다.
- `NEW-01`, `F03`, `D16-2` 등은 설계 라벨이고 `q_new_01` 등은 이 스튜디오의 편집 키다. 둘 다 기존 영속Q-ID와 자동 동일시하지 않는다. 제안 저장필드는 원문 그대로 별도 보존한다.
- 선택지의 코드·문구·그룹은 원문을 보존한다. 복합 입력은 그룹을 나누어 확인한다. 자산·채무 등 반복 상세 입력은 설계 메모로 확인하며 실제 고객용 완성 입력폼·합계 계산을 구현한 것으로 표시하지 않는다.
- 부모 응답이 바뀌면 조건부 질문은 숨길 수 있지만 기존 원응답을 임의 삭제하지 않는다. 숨긴 응답은 현재 조건의 계산에 자동 사용하지 않는다. 이 파일은 금융 계산을 하지 않는다.
- D19 상품별 이해 확인은 실제 지원 상품/정책 검증이 필요한 단계이므로 미리보기에서 보류한다. 다른 미확정 조건은 원문과 함께 표시하며 이 파일에서 개인화 추천·READY·계획채택·주문·송금을 만들지 않는다.
- 이전114개 질문 저장값은 새40개 초기값으로 자동 이관하지 않는다. 이전 브라우저 저장값과 원본은 삭제하지 않으며 필요시 이전 파일의JSON을 내보내 별도로 검토한다.

## 이번 달 실행·점검 계약

설문40개와 별도 흐름으로 설계한다. 채택한 계획ID·버전·적용일, 기록월·집계기간·기준일, 직접입력 출처와 마지막 저장시각을 연결한다.

실제 소득·생활비·대출상환·목표적립·기존투자·신규투자·비상금·추가현금저축을 입력하며 실제0·미입력·모름을 구분한다. 일시 투자금과 기존 주거자금은 월소득 배분에 합산하지 않는다. 할 일 완료와 실제 납입은 별도다. 중간 기록을 월전체 완료로 평가하지 않는다. 월말 미입력은 보완 안내, 소득 초과 배정은 이유 확인 후 기록 가능, 저장 실패는 입력값 유지, 마감 기록은 수정 이력을 보존한다. 상황 변화는 새 초안으로 재검토하고 명시적 재채택 전 기존 계획을 바꾸지 않는다.

```powershell
.\scripts\start-dev.ps1
```

앱 기본주소`http://127.0.0.1:3000`, 백엔드`http://127.0.0.1:8000`, Swagger`http://127.0.0.1:8000/docs`. 실제 설정이 다르면 현재checkout 기준을 따른다. Python 진입점은 기존 기록상`app.main:app`이며 실제코드 확인 후 사용한다. `npm run dev`만으로 백엔드는 시작되지 않는다.

```powershell
.\scripts\verify.ps1 -Mode Core
.\scripts\verify.ps1 -Mode E2E -BrowserChannel msedge
# 같은 checkout의 개발 서버가 실행 중이지 않을 때만
.\scripts\verify.ps1 -Mode Build
```

사용자·팀원의 서버를 임의 종료하지 않는다. 체크아웃·스크립트가 첨부되지 않았으므로 위 전체앱 검증은 이번 묶음에서 실행하지 않았다.
