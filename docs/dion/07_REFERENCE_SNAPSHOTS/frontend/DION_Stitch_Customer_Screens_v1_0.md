# dion — Stitch 고객 화면 디자인 지시서

2026-11-05 · v1.0 · 포트폴리오 설계 문서의 현행 고객 화면을 디자인 작업용으로 재구성

## 사용 순서 — 이 부분은 작업자 안내

이 파일을 디자인 참고자료로 제공하고, 아래 ‘시작 프롬프트’를 요청창에 붙여 넣는다. 파일을 첨부하기 어려운 경우에는 공통 규칙과 작업할 화면 절을 함께 복사한다. 원본 포트폴리오 문서 전체의 과거 수치·개발 명세를 한 번에 화면에 넣지 않는다.

1. FAST-01 한 화면의 A/B/C 스타일을 비교한다.
2. 한 스타일을 선택해 색상·폰트·카드·버튼·차트 규칙을 고정한다.
3. 같은 스타일로 FAST-02~05를 만든다.
4. 같은 시각 규칙으로 DEEP-01~05를 만든다. 정밀 화면은 별도 가상 사례를 사용한다.
5. 상담창·추가입력·보류·오류·비중편집·저장/채택 상태를 연결한다.

화면 ID·가상 사례 ID·아래 지시문은 제작자용이다. 고객 화면에 개발 명세·ID·이 문서의 표 전체를 그대로 노출하지 않는다. 고객에게 보일 문구는 각 화면의 ‘고객 문구’를 사용한다.

### 시작 프롬프트 — 그대로 복사

```text
첨부한 dion 고객 화면 디자인 지시서를 읽고 반응형 웹 UI를 디자인해줘.
이 문서의 고객 화면 구성·수치·문구·버튼·상태를 기준으로 해줘.

첫 작업은 FAST-01 ‘내 재무현황과 금융자산 구성’ 한 화면이야.
FAST-DEMO-02만 사용하고 DEEP-DEMO-01의 숫자를 섞지 마.
데이터·기능·문구를 같게 유지한 디자인 A/B/C 세 안을 만들어줘.
A: 크림·딥그린의 차분한 재무 상담형
B: 화이트·큰 숫자·넓은 여백 중심의 간결한 금융 앱형
C: 작은 고양이 도움말과 부드러운 카드 중심의 친근한 코치형

우선 데스크톱 기준 화면을 만들어줘.
내가 선택한 스타일을 나머지 화면에 이어 적용하고, 모바일 버전도 만들어줘.
화면 10개를 지금 한꺼번에 생성하지 말고 첫 화면의 스타일 비교부터 시작해줘.

확인된 결과·방향 미리보기·개인화 제안을 구분해줘.
월 차액을 투자 가능액으로 바꾸지 마.
임의 수익률·상품명·또래 평균·세금·목표 달성률을 추가하지 마.
도넛·선·세로 막대 차트를 사용하고, 가로 막대그래프는 사용하지 마.
상품 비중을 편집하는 가로 슬라이더는 그래프와 별개로 허용해.
미리보기 저장과 계획 채택, 실제 주문·송금을 구분해줘.
```

## 1. 서비스와 디자인 목표

서비스명은 dion, 로고 워드마크는 **dion.**이다. 슬로건은 ‘돈을 넘어, 당신의 삶을 설계하다.’다. 사회초년생·자산형성 초기 고객이 자신의 재무현황을 이해하고, 자금 관리 방식과 투자 구성을 검토해 이번 달 행동을 정하도록 돕는다.

첫인상은 차분함·신뢰·이해하기 쉬움이다. 중요한 숫자와 다음 행동이 눈에 들어오도록 만든다. 고객이 중요하게 여기는 생활을 무조건 줄이도록 몰아가지 않는다. 기본 화면은 카드·표·차트 중심이며 상담창은 보조 패널이다.

### 시각 방향

아래 값은 시안 제작용 출발점이다. 기존 로고·고양이 자산을 제공받으면 재사용한다. 아직 제공되지 않은 특정 고양이 이미지를 이미 확보한 것처럼 표시하지 않는다.

| 요소 | 공통 제안 |
| --- | --- |
| A안 색상 | 배경 #F7F8F2, 카드 #FFFFFF, 주요 행동 #174B3A, 본문 #202C27 |
| B안 색상 | 화이트 중심. 같은 주요 행동·상태 구분을 유지하며 간결한 배치 탐색 |
| C안 색상 | 크림·부드러운 녹색. 고양이 안내는 작은 보조 요소 |
| 글자 | 한국어 가독성이 좋은 산세리프. 본문16px, 보조14px, 핵심 금액28~36px |
| 카드 | 모서리16px, 내부 여백24px·모바일20px, 절제된 테두리·그림자 |
| 레이아웃 | PC 기준1440px·본문 최대1200px, 모바일 기준390px·1열 |
| 비교 | 재무관리2안은 PC2열, 투자구성3안은 PC최대3열. 모바일은 세로 비교 |
| 상태 | 현재·미리보기·확인 필요·채택을 색과 글자로 함께 표현 |
| 접근 | 차트와 같은 값의 표 제공. 입력 label·키보드·초점·충분한 터치 영역 |

스타일 선택 후에는 나머지 화면의 색상·글자·간격·버튼 모양을 통일한다. 화면이 바뀔 때마다 별개의 브랜드처럼 만들지 않는다.

## 2. 반드시 구분할 네 가지 개념

| 개념 | 의미 | UI 표현 |
| --- | --- | --- |
| 현재 상태 | 실제로 확인한 보유금·월 납입·현황 | 비교 기준. 제안 선택 카드와 별도 |
| 재무관리 방식2안 | 생활 안정 우선 / 투자 여력 확대 | 생활비·목표·현금·투자에 월 돈을 어떻게 나눌지 비교 |
| 투자성향 P1~P5 | 고객이 답한 선호. 검증 점수·위험 허용비중과 다름 | 선호 응답과 적용 가능한 투자 범위를 분리 |
| 투자구성3안 | 같은 신규 투자재원 내부의 A/B/C 구성 | 주식형·채권형·현금성의 차이·위험 비교 |

‘안정안·확대안’을 두 위험등급으로 만들지 않는다. A/B/C를 서로 다른 월예산처럼 만들지 않는다. ‘현재 계획 유지’를 현행 두 재무관리 방식에 제3안으로 추가하지 않는다.

### 고객 상태 문구

- **방향 미리보기:** 구성 원리·공통 예시·위험 설명을 제공한다.
- **개인화 제안 — 확인 필요:** 개인 재원·사용일·기존 보유·정책·상품 적합성 확인이 필요한 상태다.
- **검토용 초안:** 선택·비중을 비교하거나 저장한 상태다. 채택이 아니다.
- **채택한 계획:** 필수 확인 후 고객이 명시 채택한 특정 버전이다.

불확실성은 결과 옆에 짧게 표시하고, 이유·근거는 펼쳐서 볼 수 있게 한다. 화면 전체를 경고문으로 채우지 않는다.

## 3. 전체 고객 화면 지도

빠른진단과 정밀점검은 같은 응답을 이어 쓰는 상담 깊이다. 이 파일의 두 가상 사례는 원본의 서로 다른 설계 예시이므로 숫자를 합치지 않는다. 실제 고객의 정밀 전환에서는 같은 고객의 답을 재사용한다.

| 구간 | 화면 ID | 제목 | 다음 행동 |
| --- | --- | --- | --- |
| 빠른1/5 | FAST-01 | 내 재무현황과 금융자산 구성 | 자산 수정·두 관리 방식 비교 |
| 빠른2/5 | FAST-02 | 생활 안정과 투자 확대를 비교해요 | 관리 방식 미리보기 |
| 빠른3/5 | FAST-03 | 간이 투자 포트폴리오를 비교해요 | 조건 보완·구성별 상품 정보 |
| 빠른4/5 | FAST-04 | 투자상품 정보를 비교해요 | 상품 상세·결과 요약 |
| 빠른5/5 | FAST-05 | 내 결과와 이번 달 행동 | 초안 저장·점검·정밀 이어가기 |
| 정밀1/5 | DEEP-01 | 내 자산과 목표까지의 기간 | 목표 보완·두 방식 상세 |
| 정밀2/5 | DEEP-02 | 두 재무관리 방식의 자산 변화 | 조건 변경·전후 비교 |
| 정밀3/5 | DEEP-03 | 내 투자성향과 세 가지 투자안 | 구성 상세·또래 비교 펼침 |
| 정밀4/5 | DEEP-04 | 상품을 이해하고 비중을 직접 조절해요 | 편집·전후 비교·구성 검토 |
| 정밀5/5 | DEEP-05 | 그래프로 정리하는 결과와 이번 달 행동 | 초안 저장·조건 충족 시 채택·점검 |

공통 보조 UI: 필요한 정보만 묻는 입력 패널, 상품·절세 상세, 상담 패널, 저장 완료/실패, 채택 확인, 실적 기록.

## 4. 공통 화면 틀

위에서 아래 순서를 따른다.

1. 로고·빠른/정밀·현재 화면 위치·입력 수정.
2. 개인/가구·기준일·가상 사례·현재/미리보기 상태.
3. 고객이 이해할 요약 한 문장.
4. 핵심 금액 카드.
5. 화면 목적에 맞는 비교·차트·표.
6. 추가 확인할 내용과 짧은 근거.
7. 주요 행동1개와 이전/다음.
8. 우측 하단 ‘dion에게 물어보기’.

금액은 ‘만원’, 기간은 ‘월/개월/날짜’를 눈에 보이게 표시한다. 일시금과 월 납입을 같은 카드 합계로 더하지 않는다. 미입력은 ‘입력 전/확인 필요’, 확인된 없음은 ‘0원’이다. 기준일 없는 실시간 배지·연결하지 않은 계좌연동 표시를 넣지 않는다.

## 6. FAST-01 — 내 재무현황과 금융자산 구성

**고객 질문:** 이번 달 돈이 어떻게 흐르고, 보유 금융자산은 어떻게 구성되어 있는가?

**고객 문구:**

> 이번 달 돈의 흐름과 보유 금융자산을 한눈에 봐요.
> 상환과 유지할 납입을 반영한 차액을 확인하고, 내 자산이 어디에 있는지 살펴봐요.

### 위에서 아래 배치

- 헤더: ‘빠른진단1/5’, ‘현재 상태·본인 기준’, ‘입력 내용 수정’.
- KPI: 월평균 세후소득300 / 생활비160 / 월상환20 / 기존 월투자40 / 기초 차액80만원.
- 월 흐름 차트: 세로 막대 또는 항목별 카드. 80만원을 ‘신규 투자 가능액’으로 명명하지 않는다.
- 금융자산 카드2,000만원, 구성 도넛과 표: 현금·예적금1,400(70%)·기존 투자600(30%)·기타0.
- ‘현재 금융투자 비중30%’는 기존 투자600÷금융자산2,000이다. 월소득을 분모로 사용하지 않는다.
- 목적 확인표: 생활400 / 운영200 / 주거목표400. 금융자산 도넛에 별도 자산으로 다시 더하지 않는다.
- 순자산 영역: ‘보증금 등 미확인 항목이 있어 추가 확인 필요’. 미확인을0원으로 표시하지 않는다.

**짧은 설명:** ‘차액80=300−생활비160−상환20−유지할 투자40이에요. 목표 적립·현금 여유 등을 배정하기 전이므로 전부 신규 투자할 돈은 아니에요.’

**버튼:** ‘자산 금액 수정’→입력 패널 / 주요 ‘다음·두 관리 방식 비교’→FAST-02.

**추가 상태:** 구성 상세가 없으면 확인된 부분과 미분류를 보여준다. 금융자산 총액만으로70/30 도넛을 추측하지 않는다. 월상환 미확인이면 기초 차액80을 유지하지 않고 해당 결과를 확인 필요로 전환한다.

## 7. FAST-02 — 생활 안정과 투자 확대를 비교해요

**고객 질문:** 현금을 더 확보할지, 허용한 생활비 조정으로 신규 투자를 늘릴지?

**고객 문구:**

> 현금 여유를 더 쌓을지, 허용한 범위에서 신규 투자를 늘릴지 골라요.
> 목표 월 적립20만원·상환·여유금은 두 안에 모두 반영했어요.

### 배치

- 상단 공통조건: 같은 금융자산2,000만원·같은 목표·소득300만원.
- 두 카드 또는 같은 행의 비교표에 제5절 월예산을 사용한다.
- 핵심 차이: 안정은 월 전체투자40=기존40+신규0 / 확대는70=기존40+신규30.
- 신규 일시금: 안정0·현금 유지 / 확대 상한400·조건 확인 전.
- 현금 적립: 안정 월40 / 확대 월20. 목표 적립20·별도 여유금20과 구분한다.
- 이유 카드: ‘확대안은 생활비를10만원 조정하고 현금 적립20만원을 신규 투자로 옮겨요.’
- 펼침 비교: 12개월 금융자산 안정3,440 / 확대3,560만원. 같은 가상0수익·세금·비용 조건이고, 아직 목표 지급 전이다.
- 차이 설명: ‘120만원 차이는 생활비10만원×12개월 때문이에요. 일시400만원 이동으로 총자산이 늘지는 않아요.’
- 소득 변화 안내: ‘월평균 세후소득240만원이면 현재 확대안 예산 유지 시 월60만원이 부족해요. 의무지출부터 다시 확인해요.’ 빠른 사례에서 정밀 사례의 수정 투자50만원을 자동 제시하지 않는다.

**버튼:** ‘생활 안정 우선안 보기’ / ‘투자 여력 확대안 보기’→선택 미리보기 / ‘이 안으로 구성 비교’→FAST-03.

선택 예시는 확대안이다. 카드 선택으로 저장된 채택 계획을 바꾸지 않는다. 생활비 조정 미동의 고객에게 감축을 이미 적용한 것처럼 표시하지 않는다.

## 8. FAST-03 — 간이 투자 포트폴리오를 비교해요

**고객 질문:** 세 구성의 차이는 무엇이고, 내 조건에서 어디까지 검토할 수 있는가?

**고객 문구:**

> 투자 구성의 차이를 보고, 내 조건에 맞는 범위를 확인해요.
> 선택한 선호: 안정과 수익을 함께 고려. 나이로 성향이나 비중을 정하지 않아요.

### 배치

- 공통 상단: ‘확대안·신규 일시 상한400만원·월 신규30만원’.
- 영역1 ‘방향 미리보기’: 구성 원리·차이·위험. 모든 안에 비교용 예시 표시.
- 아래 A/B/C 카드·도넛·같은 항목의 표를 배치한다.

| 구성 | A·안정 보완 | B·균형 운용 | C·성장 비중 |
| --- | --- | --- | --- |
| 주식형/채권형/현금성 | 25/55/20% | 40/40/20% | 50/35/15% |
| 신규 일시400 환산 | 100/220/80만원 | 160/160/80만원 | 200/140/60만원 |
| 월 신규30 환산 | 7.5/16.5/6만원 | 12/12/6만원 | 15/10.5/4.5만원 |
| 차이 | 주식 비중을 덜 둠 | 주식·채권 비중이 같음 | 주식 비중을 더 둠 |
| 위험 | 금리·신용 위험도 존재 | 두 자산 동반 하락 가능 | 주식 변동 노출 증가 |

금액 환산은 이 문서 가상 사례를 설명하기 위한 예시다. 실제 개인 배정·추천으로 전환하려면 재원·기간·기존 노출·정책·상품 검증이 필요하다. 기본 주식비중으로 영구 적용하지 않는다.

- 영역2 ‘기존 자산·납입은 그대로’: 보유600 / 기존 월40은 별도 유지.
- 영역3 ‘개인화 제안·조건 확인’: 사용일·생활영향·경험·제외조건·기존 노출의 확인 상태.

**버튼:** ‘내 조건 확인하기’→부족정보 패널 / 각 ‘이 구성 살펴보기’→미리보기 / ‘B 구성 예시·상품 정보 보기’→FAST-04.

**확인 필요 상태:** 배정 숫자를 실제 권유처럼 강조하지 않고 예시·상한 라벨을 붙인다. 검증 전 ‘추천1위’·‘매수하기’·‘최적’ 표시와 채택 버튼을 넣지 않는다.

## 9. FAST-04 — 투자상품 정보를 비교해요

**고객 질문:** 어떤 상품군이며, 비용·위험·현금화 조건은 무엇인가?

**고객 문구:**

> 각 구성에 어떤 상품군이 들어가는지 이해해요.
> 상품 정보를 먼저 비교하고, 내게 맞는 후보는 필요한 확인을 마친 범위에서 제안해요.

### 배치

- 선택 맥락: 확대안·B구성·방향 미리보기.
- 카드3개: 가상 분산 주식형 ETF A / 가상 채권형 ETF B / 가상 현금성 상품 C.
- 각 카드에 역할, 주요 위험, 비용 확인 상태, 현금화 조건, 상세 펼치기를 둔다.
- A 역할은 주식 영역·주가/환율/국가·산업 집중 확인. B는 채권 영역·금리/신용/만기 확인. C는 투자금 내 대기자금·출금/결제/보호범위 확인.
- 실제 가격·보수·수익률은 ‘공식 자료 연결 전’으로 표시한다. 실상품 티커·가짜 시세 차트를 만들지 않는다.
- 두 설명 구획: ‘정보 비교’는 구조·비용·위험 이해 / ‘개인화 제안’은 조건 검증 후 후보 제시.
- 절세는 관련 계좌·가입요건을 확인하는 안내만 제공한다. 확인하지 않은 절세액은 표시하지 않는다.

**상세 펼침 필드:** 상품 구조·기초자산 / 원금손실·유동성 위험 / 공식 보수·기타비용·거래수수료 구분 / 시세시점·지연 / 상품자료 기준일·조회일·출처 / 고객 조건 확인 결과.

**버튼:** ‘상품별 상세 펼치기’ / ‘다음·내 결과 요약’→FAST-05.

자료가 없으면 해당 항목만 확인 필요로 둔다. 후보가0개여도 상품을 억지로 생성하지 않는다.

## 10. FAST-05 — 내 결과와 이번 달 행동

**고객 질문:** 무엇을 검토했고, 이번 달 무엇을 확인·실행해야 하는가?

**고객 문구:**

> 목표 준비와 신규 투자 구성을 함께 정리했어요.
> 지금 확인한 재원·선택한 구성·이번 달 할 일이 같은 결과에 연결돼요.

### 배치

- 상단 ‘확대안·B구성 검토 예시·채택 전’.
- 목표 카드: 총1,000·배정400·부족600만원 / 월20×30회 / 목표일2029-05-31.
- 투자 카드: 신규 일시 상한400 / 월 신규30 / 기존 월40 유지 / B 신규 월12·12·6만원.
- 월예산 세로 누적막대와 표: 생활150+상환20+목표20+여유20+현금20+전체투자70=300만원.
- 행동1: ‘목표용 돈 구분하기’·목표400과 월20 연결.
- 행동2: ‘선택한 예산 확인하기’·생활비10 조정 허용·기존 월40 유지 확인.
- 행동3: ‘신규 투자 조건 확인하기’·일시400/월30의 사용일·기존 보유·후보·비용 확인.
- 다음 점검 표: 소득·생활비·상환·기존/신규 납입·목표 잔액의 계획/실제. 실제는 ‘입력 전’.

**버튼:** ‘이 초안 저장’ / ‘다음 점검 기록’ / ‘정밀점검 이어가기’.

빠른 저장은 입력·선택·검토용 초안의 저장이다. 실제 채택은 필수 확인 후 별도 절차를 둔다. 완료 체크만으로 돈을 이체하거나 자산잔액·목표 달성을 바꾸지 않는다.

## 11. 정밀점검 가상 사례 — DEEP-DEMO-01

원본 ‘정밀점검 고객 화면’의 UI-INV-01을 디자인상 구분하기 위한 표시다. FAST-DEMO-02의 목표 배정·월 신규30만원을 섞지 않는다.

| 항목 | 정밀 가상 예시 |
| --- | --- |
| 총자산 / 부채 / 순자산 | 4,000 / 1,000 / 3,000만원 |
| 금융자산 | 2,000만원=현금·예금1,400+기존 투자600 |
| 보호·운영 배정 | 보호840+운영160만원. 이 사례의 설정이며 일반 정책 아님 |
| 목표 | 목표금액·사용일·재원 확인 전. 정밀 도달기간·목표달성률 미정 |
| 월평균 세후소득 | 300만원 |
| 안정안 | 생활160+상환20+여유20+현금적립60+월투자40=300 |
| 확대안 | 생활150+상환20+여유20+월투자110=300 |
| 신규 일시 투자 | 안정0 / 확대 목표 확인 전 상한400만원 |
| 투자 선호 | P3중립형·고객 자기보고 예시. 나이로 부여하지 않음 |
| 기본 구성 | B40/40/20%·운영 확정비중 아님 |
| 직접 조정 | 45/35/20%·검토용 미리보기 |

정밀 예시의40/110은 이 사례의 월 투자 한도 비교다. 빠른 예시의 ‘기존40+신규30=70’ 계약을 소급 적용하거나110에40을 다시 더하지 않는다. 원본의 각 사례별 월납입 의미를 실제 코드에서 대조한다.

## 12. DEEP-01 — 내 자산과 목표까지의 기간

**요약:** ‘내 자산과 투자 여력, 목표까지 걸리는 시간을 함께 봐요.’

### 배치

- KPI6개: 총자산4,000 / 금융자산2,000 / 순자산3,000만원 / 목표 도달까지‘목표·금액 입력 후 계산’ / 일시 상한400 / 월 안정≤40·확대≤110만원.
- ‘목표 준비 현황’ 카드: 목표금액·배정액·달성률은 확인 필요. 임의100%·예상N년을 그리지 않는다.
- 두 관리방식 비교 카드는 제11절 예산을 사용한다.
- 차이: 안정은 현금 확보·투자 축소, 확대는 허용 생활비10 조정·월 투자 확대.
- 상한 안내: ‘보호840·운영160을 제외한400만원도 목표 확인 전 한도예요.’

**버튼:** ‘목표 입력·확인’→목표 보완 패널 / ‘안정안 상세’·‘확대안 상세’→DEEP-02.

목표 없음은 고객의 명시 선택으로 처리한다. 목표를 아직 안 적은 것과 같게 취급하지 않는다. 목표·사용일·재원 확인 후 두 안을 재계산하고 채택 여부를 확인한다.

## 13. DEEP-02 — 두 재무관리 방식의 자산 변화

**요약:** ‘생활을 지키면서 투자 재원을 얼마나 늘릴 수 있는지 비교해요.’

### 배치

- 상단: 선택 확대안·월평균 세후소득300만원·목표 배정 전.
- 메인: 두 재무관리 방식의 금융자산 변화를 같은 축의 선그래프로 비교.
- 도넛 또는 툴팁/표로 현금·투자 구성을 구분한다. 실제 서버 데이터가 없는 중간 월 금액을 디자인 AI가 만들어 채우지 않는다.
- 설명 카드1: 생활비10×12=12개월 뒤120만원 차이. 일시400이체는 자산 증가 아님.
- 설명 카드2: 시작 현금 안정1,400 / 확대1,000만원. 보호840·운영160은 투자에서 제외.
- 조건 패널: 소득을 처음부터240으로 바꾸는 가상 사례. 확대 월110 유지 시60 부족. 생활150·상환20·여유20 유지 시 월투자50만원. 수정안12개월 금융자산2,840만원.
- 가정 라벨: 목표 미배정·수익/세금/비용0의 비교용 잔액. 부채 원금·이자 미구분이면 미래 순자산 예측 보류.

**버튼:** ‘계획 변경’ / ‘소득 변경’ / ‘지출 변경’→패널→전후 미리보기→고객 확인 후 저장. 다음 DEEP-03.

일시금 이체를 그래프 시작 총액 증가로 표시하지 않는다. 소득 변화를 실제 기록으로 저장하지 않는다. 새 조건이 늦게 응답해도 다른 버전과 섞지 않는다.

## 14. DEEP-03 — 내 투자성향과 세 가지 투자안

**요약:** ‘나의 투자성향을 확인하고, 세 가지 투자안을 골라요.’

### 배치

- P1안정형/P2안정추구형/P3중립형/P4적극투자형/P5공격투자형을 표시하고, 고객이 선택한P3에만 표시한다. 검증된 성향점수·확정 위험한도로 표현하지 않는다.
- 재원: 확대안·목표 전 일시상한400/월상한110만원.
- A/B/C 카드: 비중25/55/20,40/40/20,50/35/15. 위험 설명은 FAST-03과 같은 원칙을 따른다.

| 환산 대상 | A | B | C |
| --- | --- | --- | --- |
| 일시400만원 | 100/220/80 | 160/160/80 | 200/140/60 |
| 월110만원 | 27.5/60.5/22 | 44/44/22 | 55/38.5/16.5 |
| 안정안 월40만원 | 10/22/8 | 16/16/8 | 20/14/6 |

환산은 가상 구성 검토다. 목표·기간·기존 보유·정책 검증 전 추천·채택은 보류한다. 일시금0이면 신규 일시 도넛 대신 사유·월투자·기존600 진단을 보여준다.

- ‘현재 금융투자 비중30%’는 기존600÷금융자산2,000이다.
- 선택 펼침 ‘또래 비교’: ‘20~29세·같은 자산 기준의 통계 확인 후 표시 / 현재는 비교 가능한 평균 자료 확인 중’.
- 평균 수치·격차·백분위·순위를 창작하지 않는다. 신규 구성비40/40/20과 전체 금융투자비중30%를 직접 비교하지 않는다.

**버튼:** ‘이 안 비교하기’ / ‘선택 예시·상세 보기’→DEEP-04 / ‘또래 비교 펼치기’→정보 패널.

## 15. DEEP-04 — 상품을 이해하고 비중을 직접 조절해요

**요약:** ‘상품의 역할과 위험을 보고, 내 구성으로 바꿔볼 수 있어요.’

### 배치

- 상단: ‘확대안·기본 B40/40/20에서 직접 조정45/35/20한 예시·목표 확인 전 한도’.
- 신규재원 표시: 일시400 / 월110만원. 기존 보유600 자동매도 없음.
- 상품3행에 색상점·상품명·슬라이더·직접 비중 입력·일시금·월액을 배치한다.

| 상품 | 조정비중 | 일시금 | 월액 |
| --- | ---: | ---: | ---: |
| 가상 주식형 ETF A | 45% | 180만원 | 49.5만원 |
| 가상 채권형 ETF B | 35% | 140만원 | 38.5만원 |
| 가상 현금성 상품 C | 20% | 80만원 | 22만원 |
| 합계 | 100% | 400만원 | 110만원 |

- 합계 상태: ‘직접 조정 중·추가 확인 필요’.
- 변경 전후 도넛·금액표: 기본B와 직접조정을 같은 신규재원 분모로 비교.
- 상품 설명·위험·공식출처 펼침 및 절세 적용조건 펼침을 아래에 둔다.
- 절세 구획: ISA/투자자산, 연금저축·IRP, 주거·기타자산의 해당 요건 확인. 모두 현재 추가 확인 필요. 자동 공제액·절세액 생성 금지.

### 슬라이더 동작

1. 0~100%,1%p 단위, 직접 입력·키보드 조절 지원.
2. 잠금 상품 비중은 유지하고, 잠기지 않은 현금성 항목으로 잔여를 맞춘다.
3. 잔여가 음수인 편집은 적용하지 않고 가능한 범위를 안내한다. 현금성 항목도 잠겨 조정할 수 없으면 잠금 해제를 요청한다.
4. 합계100%·비음수·원단위 합계와 정책·자금·사용일·상품 적합성을 확인한다. 미정 한도를 임의 생성하지 않는다.
5. 편집 시 도넛·일시/월액·위험 안내·DEEP-05·같은 버전 내보내기에 반영한다.
6. 재원 총액·보호/목표자금을 슬라이더만으로 늘리지 않는다. 기존 채택 계획은 유지한다.

**버튼:** ‘기본 구성으로 되돌리기’ / ‘변경 전후 비교’ / ‘이 구성 검토하기’→DEEP-05.

허용 범위를 벗어나면 검토용 초안으로만 보관하고 채택은 막는다. P3 선호 자체를 슬라이더에 맞춰 바꾸지 않는다.

## 16. DEEP-05 — 그래프로 정리하는 결과와 이번 달 행동

**요약:** ‘선택한 신규 재원의 변경 전후 구성과 이번 달 확인할 일을 정리했어요.’

### 배치

- 상단: 확대안·직접조정45/35/20·목표 확인 전 상한·실행 전.
- 변경 전후 도넛: 신규 일시400의 B40/40/20→45/35/20. 월110은 별도 분모·별도 표.
- 조정 후 월액49.5/38.5/22만원, 합계110만원.
- 자산변화 요약은 DEEP-02의 같은 조건을 재사용.0수익/비용 가정에서 비중 편집만으로 총액이 증가하지 않음.
- 행동 카드: 생활비·필수지급 / 일시 재원 / 월투자 / 계좌·상품 확인. 실행계좌·납입일 미확인은 확인 과제로 남김.
- 실적 표: 소득300/생활150, 상환20/별도여유20, 월투자110/일시400의 계획·실제. 실제는 ‘입력 전/실행 전’.
- 실제 입력 후 계획/실제의 같은 기간을 세로 막대로 비교. 미입력을0으로 그리지 않음.

**버튼:** ‘변경 확인 후 초안 저장’ / ‘이 버전 PDF 받기’ / ‘다음 점검 기록’. 원본의 ‘계획 저장’은 채택 전 검토용 저장으로 의미를 명확히 한 UI 제안이다.

필수 확인이 충족된 상태를 별도 변형 화면으로 디자인하고 그때만 ‘이 계획으로 시작하기’를 제공한다. 이 문서 예시 자체는 목표·사용일 등 검증 전이므로 성공 채택·주문·송금 화면으로 자동 넘어가지 않는다.

## 17. 공통 보조 화면과 상태

### 17.1 필요한 정보만 보완하는 패널

‘이 결과를 확인하려면 이 정보가 필요해요’와 확인 이유를 먼저 보여준다. 이미 답한 정보는 요약만 표시한다. 요청한 결과의 부족한 항목만 추가한다.

예: 자산 구성→F06보완 / 상환→기존 조건부 응답 / 목표→금액·사용일·배정금 / 투자→재원·기간·생활영향·선호·경험·제외조건. 이 라벨을 고객 화면에 문항ID처럼 노출하지 않는다.

소득은 전 구간 월평균 세후소득이다. 기준기간·범위·일회성 포함 여부를 확인하며 대출·계좌이체·매각대금을 반복소득에 넣지 않는다. 모름·없음·미입력을 구분한다. 이 디자인 작업으로 새 영속 Q-ID나 추가 필수 질문 개수를 정하지 않는다.

### 17.2 상담 패널

- 닫힘: 우측 하단 ‘dion에게 물어보기’.
- 열림: PC우측 패널 / 모바일 전체 높이 패널 제안.
- 상단: dion 상담·최소화·닫기. 대화 이어가기·이전 대화 보기.
- 본문: 메시지·입력창·보내기. 이전 화면의 대화는 같은 결과 맥락으로 이어짐.
- 빠른 예시 질문: ‘기존 투자40만원도 다시 나누는 거야?’
- 답변 예시: ‘기존 월40만원은 유지해요. 이 구성 예시는 추가로 검토할 월30만원과 일시 상한400만원에만 적용했어요.’
- 조건 변경 요청→전후 미리보기→고객 확인 후 저장. 대화로 즉시 채택·매수하지 않음.
- 상담 실패→재시도·기본 결과 유지. 입력이 바뀌면 이전 답변이 이전 기준임을 표시.

### 17.3 상태별 디자인

| 상태 | 화면 표시·복구 행동 |
| --- | --- |
| 로딩 | 요청한 영역에 skeleton·계산 중. 임시0원 수치 금지 |
| 정보 부족 | 누락 내용·영향 결과·필요 질문으로 연결. 확인된 다른 현황은 유지 |
| 정책 확인 중 | 관련 개인화 배정만 보류. 고객에게 정책의 정답을 입력하게 하지 않음 |
| 적자·실행 불가 | 부족액·시점·가능한 조정. 적자를0으로 숨기지 않음 |
| 상품자료 없음·오래됨 | 자료시점·비교 제한·재확인. 가상 수치로 대체하지 않음 |
| 후보0개 | 조건에 맞는 후보가 없다는 정상 결과. 조건 점검·정보 비교 제공 |
| 입력 변경 | ‘입력 내용이 바뀌었어요. 다시 계산해주세요.’ 이전 결과 채택 차단 |
| 저장 실패 | 작성값 유지·재시도. 저장되었다고 표시하지 않음 |
| 내부 처리 오류 | 실패 영역·재시도. 고객 입력이 틀렸다고 안내하지 않음 |
| 채택 확인 | 범위·변경·금액·필수 확인 요약. 서버 성공 전 완료 표시 금지 |

### 17.4 차트 규칙

- 구성비는 도넛, 기간별 변화는 선, 금액·계획/실제 비교는 세로 막대를 사용한다. 가로 막대그래프는 사용하지 않는다.
- 분모를 차트 제목에 명시한다: 금융자산전체/신규일시금/월신규납입/정밀월한도.
- 자산잔액과 월현금흐름을 같은 도넛으로 합치지 않는다.
- 분모0·미정은 비율 계산 보류. 적자는 세로막대와 부족금액으로 표시한다.
- 모든 차트에 금액·비중·기준시점·가상 가정 표시와 같은 값의 표를 제공한다.
- 금융자산 그래프를 미래 순자산으로 바꾸지 않는다. 목표 지급 전후·일시금 이동을 구분한다.
- 미확인 또래 평균·백분위·수익률·그래프 중간값을 창작하지 않는다.
