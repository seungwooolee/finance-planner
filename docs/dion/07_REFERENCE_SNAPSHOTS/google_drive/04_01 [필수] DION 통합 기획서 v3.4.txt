확정 · 생애단계별 기본 결과와 목표 우선 원칙 · 2026-11-03

사회초년생: 비상자금·부채를 고려한 투자 시작 가능액과 월 투자계획.

확정 · MVP 구현 깊이: 여섯 단계 모두 공통 상담 흐름을 제공하고 단계별 핵심 결과 하나씩을 입력→진단→계획 비교·채택→실행→사후 점검까지 연결한다. 복잡한 연금·세금·상속 정밀 계산은 후속 확장으로 둔다. 은퇴기의 인출 흐름은 기존 월 저축·투자 계산을 보완해야 하며 산식·검산은 별도 설계한다. 이번 결정은 구현·검증 완료를 뜻하지 않는다.

확정 · 대상과 기본 표시: 예적금·주식·채권·ETF·펀드 등 금융자산의 기존 보유와 신규 투자금을 함께 고려해 재구성한다. 보험·연금은 이번 MVP의 수집·진단·추천·재구성 대상에서 제외하며 보험·연금 전용 질문·카드·상품 및 연금저축·IRP 제안을 제공하지 않는다. 제외 자산을 0원으로 간주하지 않으며 결과 합계는 ‘분석 대상 금융자산 기준’으로 표시한다. 은퇴기에도 이 범위의 생활비·확인된 소득·인출·투자 흐름을 다루며 종합 노후준비 진단으로 표시하지 않는다.

확정 · 재무계획 2안과 투자 구성 연결 · 2026-11-03
재무계획은 ‘안정 중심’과 ‘투자 중심’ 두 가지다. 두 안은 같은 고객정보·기준일·생활비·목표 시점·공통 자금 제약으로 비교한다. 필수 생활비·의무상환·필수 목표자금·최소 비상자금을 공통으로 확보한 뒤 남는 자금에서 안정 중심은 추가 현금 여유, 투자 중심은 투자 가능한 장기자금 배정을 우선한다. 생활비·목표 시점은 고객이 변경에 동의했을 때만 조정하며 변경 조건을 표시한다. 투자 중심이라는 이유로 위험등급을 높이지 않는다. 실제 배분 금액·현금 여유 기준·산식은 후속 정책 설계·검산에서 확정한다.

계획·투자 구성의 미리보기와 실행계획 명시 채택은 구분한다. 첫 화면 요약과 화면 3 상세는 같은 선택 결과를 참조한다. 아래 기존 3안/PORT-01~03 설명은 개편 전 참고이며 현행 2안 UI 생성 기준으로 사용하지 않는다. 기존 식별자·채택 이력·실적·검산 사례를 삭제하거나 새 2안의 ID로 재해석하지 않는다. 원장·상세 구현 명세·코드의 이관과 정책 검증은 후속 작업이며 이번 문서 결정만으로 완료되지 않는다.
우선 해결할 문제: ‘내 상황에서 얼마를 투자할 수 있고, 어떤 투자 구성을 검토하면 좋을까?’ 투자 포트폴리오와 대표 상품의 선택 이유를 쉽게 이해하도록 돕는다. 재무진단·보호자금·부채·목표·자금 사용 시점은 개인화 제안의 근거이며 투자 중심 화면과 함께 연결한다. ‘금융 투자를 강조한다’는 제품 방향이며 시장 트렌드의 실증 검증 결과를 뜻하지 않는다.
2. 처음 사용한 고객에게 줄 가치
현재 상태 이해: 수입·생활비·상환·보유자금·목표를 바탕으로 월 여력과 준비 상태를 쉬운 말로 보여준다.
투자 포트폴리오 이해: 투자 가능한 금액과 주식성·채권성·현금성 등 구성의 의미, 선택 이유를 전면에 보여준다. 전체 자산의 목적별 배정·월 신규 배분·투자금 내부 구성은 각각 구분한다. 투자 강조를 고위험 비중 확대나 투자 필수로 해석하지 않는다.
실행할 계획 선택: 안정 우선·현재 생활 유지·목표 달성 우선안을 비교하고 이번 달 행동을 정한다. 목표 달성 우선안을 고른다고 위험성향이 바뀌지는 않는다.
상황에 맞춘 수정: 실행 결과와 소득·지출·목표 변화를 입력하면 원안과 차이를 확인하고 수정 계획을 다시 선택한다.
3. ‘쉽고 빠르다’의 기준
기본 입력부터 첫 진단 확인까지 5분 안팎은 미확정 설계 목표로 남긴다. 투자 구성·대표 상품 제안에 추가 확인이 필요하면 이유와 남은 질문을 보여준다. 전체 투자 상담 완료 시간을 보장한 것으로 표시하지 않는다.
한 번에 모든 항목을 묻지 않는다. 결과에 필요한 기본 질문부터 받고, 부채·투자·보험·연금 등은 해당 결과에 필요할 때 추가한다. 이미 입력한 답은 재사용한다. 질문 개수와 정확한 문구는 2단계에서 정한다.
결과는 핵심 진단 → 비교할 계획 → 이번 달 할 일 순서로 먼저 보여주고, 차트·계산 근거·용어·상품 세부 정보는 펼쳐서 볼 수 있게 한다. 정보가 부족하면 확인된 결과부터 제공한다.
4. 이번 MVP에 넣을 기능
필수 흐름: 서비스 범위·정보이용 확인 → 최소 정보와 대표 목표 입력 → 현재 상태 진단 → 자산·투자 포트폴리오 및 세 계획 비교 → 명시 채택 → 이번 달 실행·실적 기록 → 사후 점검·수정안 재채택.
제안 범위: 대표 목표 1개부터 지원한다. 세 계획의 차이·장단점·부족액·고객이 허용한 변경을 설명하고, 같은 결과로 계산된 안은 동일하다고 표시한다. 자금이 부족하거나 조건이 미확정이면 이를 숨기지 않는다.
투자·대표 상품: 실상품의 가격·수익률 순위나 비교표 대신 투자 구성 카드 안에 ‘대표 상품’을 제시한다. 해당 자산군·전략의 역할을 설명하고, 확인된 고객의 투자기간·선호·투자 여력·유동성·목표·기존 노출을 충족하는 범위에서 개별 상품과 연결한다. 먼저 예적금·ETF로 범위를 자동 확정하지 않고 결과 설계에서 필요한 상품군을 정한 뒤 검증한 소수 후보를 조사한다.
AI·점검: AI는 필요한 추가 질문과 검증된 결과의 설명을 돕는다. 기본 계산·계획 선택·실적 기록은 AI 응답 없이도 사용할 수 있게 한다. 공모전 시연은 가상 고객 1명의 가상 한 달 후 점검까지 연결하며 모의 실적을 실제 고객 성과로 표시하지 않는다.
5. 후속으로 확장할 범위
거시경제 자동 반영, 전 금융상품 실시간 수집, 마이데이터 계좌 자동연동, 자동매매, 고급 최적화, 복잡한 상속·정밀 세무·연금 계산, 여러 목표의 동시 최적화는 핵심 상담 경로 이후로 둔다. 현재 입력·관련 질문·보유 정보의 활용 가능 범위는 유지하고, 지원하지 않는 분석을 완성된 결과로 표시하지 않는다.
6. MVP가 완성됐다고 판단할 기준
고객 이해: 고객이 자신의 현재 상태, 선택한 계획의 이유, 이번 달 할 일을 자기 말로 설명할 수 있다. 기본 진단까지 걸린 시간·이탈·추가 질문의 이해도를 실제 사용성 점검에서 기록한다.
계산·실행: 같은 입력과 버전에서 화면·저장값·보고서 숫자가 일치하고, 재원 중복·의무지출 누락·허용 범위 초과·미확인을0으로 바꾸는 오류가 없다. 월 여력과 목표기한 충당, 실제 지급일 안전은 각각 확인한다.
6단계 연결: 가상 고객이 계획을 비교·채택하고, 행동과 모의 실적을 기록한 뒤, 가상 한 달 후 원안·차이·수정안·재채택까지 실제 앱에서 완료한다. 검토 기록은 실제 실행·사용자 확인·전문가 검토를 구분한다.
7. 반영한 사용자 결정과 남은 검토
고객 범위 결정: 직장인으로 좁히지 않는다. 직업·소득 형태에 따라 필요한 질문을 분기하며 기존 직장인 시연 사례를 전체 고객의 자격 조건으로 사용하지 않는다.
핵심 가치 결정: 투자 포트폴리오와 투자 판단의 이해를 전면에 둔다. 재무진단과 이번 달 실행·사후 피드백은 이를 뒷받침하는 핵심 흐름으로 유지한다.
상품 제시 방식 결정: 이미지처럼 투자 구성 카드 안에 대표 상품을 제시하고, 고객 조건과 연결한 선택 이유를 설명한다. 실상품 비교·인기 순위·수익률 경쟁을 별도 핵심 기능으로 만들지 않는다. 상품 정보·적합성·제공 범위 검증은 필요하다.
속도 목표: 첫 진단 5분 안팎이라는 제안을 유지할지. 전체 상담·투자 구성 완료까지 같은 시간을 보장하는 뜻은 아니다.
남은 수정 공간: 첫 진단 속도 목표 [                         ] / 첫 화면에서 보여줄 투자 결과 [                         ] / 우선 검토할 상품군 [                         ] / 뒤로 미룰 기능 [                         ]
대표 상품 제안 카드 — 다음 결과 설계에 반영할 기준
표시 흐름: 투자 가능 금액 → 제안 투자 구성·자산군별 역할 → 해당 구성의 대표 상품 → 나와 연결되는 이유·위험·비용 → 이번 달 검토/실행 행동. 세 가지 재무계획의 비교는 유지하되 금융상품 간 비교표와 구분한다.
카드 필수 정보: 검증한 상품명·상품 유형·실질 투자대상, 구성 내 역할, 고객 조건과 연결한 제안 이유, 주요 위험·비용·유동성, 자료 기준일·공식 출처. 고객의 투자기간·선호 외에도 필수자금·목표·투자 여력·환노출·기존 보유와의 중복을 확인한다.
문구 초안: ‘입력하신 투자기간과 투자선호, 필수자금과 목표를 제외한 투자 여력을 바탕으로 검토할 수 있는 대표 ETF입니다. 이 상품의 [확인된 투자대상·구조]가 제안 구성의 [역할]과 연결됩니다. [주요 위험]과 비용을 함께 확인해 주세요.’ 개인화 기준을 확인한 경우에만 이 문구를 사용한다.
‘적합할 가능성이 높다’는 문장은 검증한 선정 근거가 있을 때 검토한다. 검증되지 않은 적합 확률·등급·수익 전망을 만들지 않으며 근거가 부족한 일반 예시를 개인화 결과처럼 설명하지 않는다.
이미지 활용 범위: 카드와 펼침형 대표 상품 목록의 구성을 참고한다. 이미지에 있는 일임투자·최소운용금액·투자자 수·또래 인기·환율 영향·특정 상품 위험 표시는 우리 서비스의 확인된 사실로 복사하지 않는다. 표시 통화와 실제 기초자산의 환노출은 별도로 확인한다.
제공 범위 검토: 고객 조건에 따라 특정 ETF를 골라 제시하는 기능은 개인화 제안이므로 ‘대표 상품’이라는 표기만으로 법적 검토가 해소된다고 가정하지 않는다. 금융위원회의 2022년 맞춤 포트폴리오 관련 해석과 2024년 유사투자자문업 안내를 참고하되 실제 운영 형태에 대한 최종 판단으로 일반화하지 않는다. 공모전 가상 사례와 실제 고객 운영의 검증 범위를 구분한다.

아래는 이전 상세 기획이다. 위 초안의 검토·수정 후 필요한 내용만 현행 MVP에 반영한다. 아래 사례의 숫자와 과거 정책은 새 대상 고객의 기본값으로 자동 적용하지 않는다.
타깃 고객과 문제 정의
1차 고객: 취업 초기~자산 형성 초기 사회초년생. 자신의 돈을 '얼마를 투자할지'보다 먼저 '언제 사용할 돈인지' 구분하고 싶지만 재무·세제·투자상품 정보가 분산되어 있는 상황을 해결한다.
문제 가설 H1: 투자성향 설문만으로 상품을 고르면 비상자금·부채·주거목표와 충돌할 수 있다.
문제 가설 H2: 같은 상품도 계좌·과세연도·보유 기간·수수료에 따라 고객에게 적합한지 달라질 수 있다.
문제 가설 H3: 금융상품 이름만 나열하면 선택 이유와 손실 가능성·실행 조건을 이해하기 어렵다.
위 세 문제는 실제 사용자 조사·전문가 리뷰가 필요한 가설이다.
대표 시연 고객: 기존 v2.1 사례 계승(잠정·검증 전)
27세 수도권 1인 가구 직장인, 세후 월 소득 300만원, 월 소비성 지출 220만원, 월 최초 여유금 80만원.
현재 자산 2,200만원 = 월세 보증금 1,000만원 + 주거 저축 400만원 + 비상자금 600만원 + 장기투자 200만원. 부채 0원. 5년 후 주거자금 목표 7,000만원.
이 수치는 시연을 위한 가정이지 실제 평균값·적정 투자액·상품 권유가 아니다. 새 포트폴리오 알고리즘에서는 보증금의 유동성, 비상자금의 용도, 기존 장기투자 내역을 따로 처리한다.
기존 기초 물가 예시는 관리비·공과금 15만원, 식비·교통·통신비 70만원, 여가·쇼핑 45만원의 합계 130만원. 새 MVP의 메인 투자 설계에서 물가 0/3/5%는 선택적 스트레스 테스트로 사용한다.
고객에게 제공할 가치
내 돈의 구조: 전체 자산·부채·고정 지출 및 현금 여력을 구분해서 보여준다.
목표별 설계: 비상자금·주거·은퇴처럼 사용 시점과 목적에 따라 자금을 구분한다.
적합한 위험만: 위험 선호, 위험 감내 능력, 투자 이해도, 투자기간을 별도로 검사하고 금지 조건을 적용한다.
상품 설명의 투명성: 상품 후보별 선택 이유·위험·비용·세제 가정·출처와 대안을 제시한다.
생활 변화 대응: 실직·물가·시장 하락 등으로 계획이 달라질 때 원안과 수정안을 비교한다.
고객 경험의 범위
필수 질문은 적게 시작하고 사용자의 답에 따른 추가 질문을 단계적으로 제시한다. 고용상태·주거형태·부채·연금·투자경험에 따라 분기한다.
입력한 값/고객이 인정한 예시 가정/공식 관측값/미확인 항목을 명시적으로 구분한다. 숫자를 모르면 무조건 0으로 저장하지 않는다.
결과는 자산 포트폴리오와 투자 포트폴리오를 분리해 제시한다. 투자의 기대 성과는 확정 또는 보장하지 않는다.
주요 기능의 우선순위
P0: 6단계 전체 흐름, A~D 결과 화면, 대표 목표1건, 재원 중복·지급일 검사, 세 계획 비교·명시 채택, 월 실행·수동 사후 점검, 조건을 충족한 투자 분석, AI 선택 해설과 팀원용 AIQC-01 수동 검토·내보내기. 미검증 투자정책은 사유와 함께 보류해 기본 흐름을 유지한다.
P1: 검증된 개별 상품 소수 비교, 산업·기업 비교, 조건부 보유내역, 선택형 생애 사건, 세금·비용 검증 모듈. 현재는 설계·검토 대상이며 실시간 API·개별상품·세무 결과가 구현·검증됐다는 뜻이 아니다. 거시경제는 핵심 사례 이후로 둔다.
P2: 고급 최적화, 자동 알림·외부 금융정보 수집, 실거래 연동·자동 리밸런싱. 수동 사후 점검과 이전·수정 계획 비교는 P0이므로 이 범주에 포함하지 않는다.
성공 판단
대표 가상 고객 1명이 ① 범위 확인 → ② 정보·목표 확인 → ③ 진단 → ④ 대안 비교·계획 채택 → ⑤ 이번 달 행동 기록 → ⑥ 가상 한 달 후 실제 결과·상황 입력 및 수정 계획 채택까지 완료한다. 원안·수정안·근거와 보고서 숫자가 일치해야 한다.
각 계산·금융상품 정보는 출처/기준일/가정 버전과 함께 재현되고, 제약을 위반한 제안은 차단된다.
간편·정밀 진단 전략
간편 진단은 적은 질문으로 현재 현금흐름·자산/부채·목표와 부족 정보를 보여준다. 정밀 진단은 이미 입력한 답을 이어받아 위험·목표별 자금·보험/연금·제약을 보완한다. 정밀 필수값이 없으면 투자 적합성·개인별 배분을 확정하지 않는다.
기본 진입은 쉽고 빠른 상담으로 통합한다. 결과에 필요한 기본값부터 받고 투자·보유·보험·연금 등은 필요한 순간에 심화한다. 기존 간편/정밀 데이터·답변은 재사용하고 두 경로를 처음부터 모두 필수로 요구하지 않는다.
질문 확장: 생애 사건과 가족 책임
보험·연금 외에 상속·증여·가족 지원, 부양·간병, 결혼·출산, 교육·휴직·창업, 목돈 지출, 자산 현금화 가능성, 공동재무와 목표 조정 여력을 선택 심화 후보로 정리한다. 해당 여부를 먼저 확인하고 필요한 사건만 추가 질문한다.
* 우선 반영 제안: 가족 지원/부양, 소득 안정성, 부채, 자산 사용 가능 시점, 목표 조정 여력.
* 선택 사건: 결혼·출산·육아, 교육·휴직, 차량·이사 등 목돈 지출. 사건별 금액·시점·비용 분담과 소득 공백을 연결한다.
* 후속 검토: 복잡한 상속·사업승계·정밀 세무·창업 손익·장기 은퇴 정밀 계산. 조사 범위가 큰 항목을 공모전 필수 구현으로 자동 확대하지 않는다.
가족에게 ‘받을 지원/상속’과 ‘줄 증여/상속’을 구분한다. 불확실한 유입은 필수 재원에 넣지 않고 지원 없음/있음 대안으로 비교한다. 비금전적 가치와 경력·가족 만족을 임의 금액으로 환산하지 않는다.
질문 간소화와 분석 범위
Q-010 총생활비를 한 번 공통 질문한다. Q-011 필수생활비는 비상자금·소득공백·재무 손실감내 평가가 필요할 때만 추가 질문한다. Q-137은 미노출하고 Q-011로 연결한다. 정보가 없으면 해당 정밀 결과를 보류한다.
현재 보유자금의 배분과 매월 여유금의 배분을 별도로 설명한다. 현금 부족·미확인 입력·미승인 기준이 있으면 개인별 투자 비중을 확정하지 않는다. 목표를 모르면 기본 진단만 제공하고 금액·시점을 임의로 채우지 않는다.
03 고객 여정과 재무설계 6단계
전체 사용자 Flow
상위 프로세스: ① 서비스 이해·범위 확인 → ② 고객 정보·목표 설정 → ③ 상황 분석·평가 → ④ 세 가지 계획 비교·선택 → ⑤ 이번 달 실행 지원 → ⑥ 실적·상황 점검 및 재설계. 6단계는 기능·고객 결정의 기준이며 화면 개수와 같을 필요는 없다. 변화가 있으면 ⑥에서 필요한 선행 단계로 돌아간다.
1단계 고객과의 관계 정립
제공하는 도움·지원하지 않는 범위, AI와 계산 엔진의 역할, 고객·플랫폼의 실행 책임, 정보 이용 목적·외부 전송·저장·삭제 안내를 확인한다. 실제 구현된 저장 정책만 안내하며 전문자격을 보유한 사람처럼 표현하지 않는다. 완료 기준: 고객이 범위·안내 버전을 확인하고 필요한 동의를 남김.
출력 증거: 분석 범위, 목표·우선순위, 서비스 제한사항 및 설명 확인 기록.
2단계 정보 수집 및 목표 설정
필요한 소득·지출·자산·부채와 가족 부양·직업·자금 사용 시점을 조건부 수집한다. MVP는 최우선 목표 1개의 이유·금액·시점과 유지하고 싶은 생활 수준, 지출·목표일·목표규모의 조정 허용 범위를 확인한다. 건강은 재무계획에 관련된 비용·소득 공백 중심으로 필요한 때만 묻는다. 완료 기준: 고객이 입력·목표·허용한 변경을 확인하고 미확인 값을 구분함.
출력 증거: 고객 프로필, 미확인 항목과 질문 이유, 목표별 금액·시점·우선순위.
3단계 현재 상황 분석 및 평가
현금흐름·자산/부채·유동성·목표 부족액을 계산하고 삶의 조건과 함께 강점·걸림돌·목표 실현 가능성을 설명한다. 보유액과 월 배분액, 투자 선호와 실제 감내 능력을 구분한다. 완료 기준: 필요한 입력과 근거로 계산을 재현할 수 있고 미확인 값에 의존한 결과는 보류함.
출력 증거: 재무진단 카드, 사용 가능한 현금·목표 전용자금·투자 가능자금, 검산 결과와 위험 경고.
4단계 재무설계안 작성 및 제시
같은 고객정보·기준일·공통 제약으로 ① 안정 우선안 ② 현재 생활 유지안 ③ 목표 달성 우선안을 비교한다. 각 안의 목적별 자산 배분, 조건 충족 시 투자금 내부 배분, 월 필요금액·목표 예상 시점·생활 여유·장단점·가정을 제시한다. 미검증 상품은 상품군 설명에 한정한다. 완료 기준: 고객이 계산 가능한 안을 비교·수정하고 채택 여부를 명시함.
출력 증거: 대안 비교표, 추천/제외 이유, 상품 팩트시트와 기준일, 시장 충격 테스트.
5단계 실행 지원
채택한 계획을 이번 달 행동으로 바꿔 무엇·금액·기한·담당·선행조건을 제시한다. 미착수·진행 중·완료·보류와 실제 실행 금액·날짜·사유를 기록한다. 실행 완료와 자산·목표의 실제 성과는 구분한다. 완료 기준: 선택한 계획 버전에 연결된 실행목록과 상태 기록이 있음. 외부 계좌 이체·상품 매수는 앱에서 실행하지 않는다.
출력 증거: 실행계획(누가/언제/얼마/전제조건), 고객의 선택과 미실행 사유.
6단계 실행 경과 및 상황 모니터링
고객과 점검 주기·방법·범위를 정하고 실제 저축·상환·지출 및 소득·자산·부채·목표 변화를 수동 입력한다. 계획 대비 차이와 원인을 설명하고 ② 정보 갱신·③ 재진단·④ 재제안 중 필요한 단계로 돌아간다. 완료 기준: 다음 점검일, 이전·실제·수정 결과, 변경 이유와 고객의 수정 계획 채택 여부를 보존함.
출력 증거: 최초·수정 run_id, 변화 로그, 경고·재계산 결과, 다음 확인 시점. MVP는 수동 재입력 방식.
새 화면 구조(6단계와 매핑)
상위 내비게이션은 ① 시작·범위 ② 내 정보·목표 ③ 진단 ④ 계획 비교·선택 ⑤ 이번 달 실행 ⑥ 사후 점검으로 통일한다. 기존 S01~S05는 유지하고 S06 실행(⑤)·S07 사후 점검(⑥)으로 구분한다. S04 포트폴리오와 S05 상품 설명은 모두 ④에 속한다. 하나의 화면에 탭으로 묶을 수 있으나 상태·기록·완료 기준은 분리한다.
기존의 4개 화면을 그대로 유지할 필요는 없다. 이 6화면은 정보구조 초안이며 실제 화면 구조/상호작용은 상세 명세서 ⑤에서 확정한다.
핵심 사용자 보호 원칙
위험성향 점수만으로 금융상품 추천을 확정하지 않는다. 가까운 시점에 필요한 돈, 비상자금, 상환 약정과 손실 감내 능력을 먼저 검사한다.
과거 수익률·가정 수익률은 미래 성과의 확률 또는 보장이 아니다. 세금/연금 추정치는 과세연도와 고객 입력 충족 범위를 밝혀 표시한다.
AI 에이전트가 제공할 경험
고객의 자연어 요청을 이해하고, 현재 분석에 필요한 정보만 질문한다. 서버가 검증한 고객 상태와 계산 도구를 사용해 결과를 설명하고, 고객이 허용한 변경안만 재계산한다. 질문 CSV는 기준과 조건의 원장이며 실제 답변은 고객 상태에 저장한다.
고객 예: ‘전세로 옮기고 싶다’ → 보증금·시점·대출·현재 자금 확인 → 실행 가능성 계산 → 부족/제약 설명 → 고객이 허용한 시점·예산 변경안 재계산. 지원되지 않는 세금·대출 조건은 확인 필요로 남긴다.
질문 경험의 품질 기준
* 기본 질문은 빠진 필수 정보, 확인 질문은 모호한 단위·충돌, 결과 질문은 부족액·제약에 대한 고객의 조정 의사를 확인한다.
* 질문 이유를 보여주고 모름·응답하지 않음·해당 없음·실제 0을 구별한다. 이미 확인한 정보를 중복 질문하지 않는다.
* 숫자와 그래프는 계산 결과를 직접 표시한다. AI는 같은 실행의 근거를 설명하고, 새 목표나 고객 답변을 임의로 확정하지 않는다.
최소 시연의 완료 모습
대표 고객으로 입력 → 필요한 정밀 질문 → 진단 → 보호자금/투자 가능액 → 두 포트폴리오 → 상품군 설명 → 실행계획 → 수정 후 재점검을 연결한다. 개별상품은 검증 완료 후보만, 충격 시나리오는 지원 범위만 제시한다. 투자 가능·투자 보류·정보 부족의 세 사례를 확인한다.
세 가지 안의 공통 기준
차트 클릭은 미리보기이며 ‘이 계획으로 시작하기’가 계획 채택이다. 필수생활비·의무 납부·확정 지출·승인된 보호자금·위험 제약은 모든 안에 공통 적용한다. 목표 달성 우선안을 선택해도 투자 위험성향을 자동 상향하지 않는다.
고객이 허용한 지출·목표일·목표규모만 변경한다. 같은 결과의 안은 차이를 설명하고, 정보 부족·검토 대기·실행 불가인 안은 상태와 필요한 조건을 표시한다. 세 개를 맞추기 위해 숫자·수익률을 생성하지 않는다.
피드백에서 돌아갈 단계
소득·가족·목표·선호 변경은 ②에서 확인하고 ③ 재진단으로 연결한다. 입력 변화 없는 실적 차이는 ③에서 원인을 점검한다. 배분·목표 일정 조정이 필요하면 ④에서 새 대안을 제시하고 고객 채택 후 ⑤ 실행계획을 갱신한다. 변화가 없으면 기존 계획 유지와 다음 점검을 기록한다.


2026-11-02 · 결과 화면과 여정 정리
6단계는 업무 과정, A~D는 결과 화면의 네 영역이다. A 자산(총자산·부채·순자산·사용가능액) → B 현재 금융자산 구성 → C 대표 목표의 확보액·부족액·납입일정 → D 안정 우선/현재 생활 유지/목표 달성 우선 비교 순서로 보여준다.

미해결: 규칙 적용/차단 조건, 변수 32종 연결, 보증금 반환 전 유동성, 대표 필드 통일, 실제 상품 공시. QA T-001~T-034는 기대 결과를 정의한 목록이며 실제 결과는 미실행이다. 먼저 투자 가능·투자 보류·정보 부족 사례와 중복계상 반례를 검증한다.
