## 2. 재무엔진의 남은 정책 정리

현재인계v1.6의19/20절을재사용한다. 엔진을LLM출력으로만들지않는다.

- 현재현황: 자산·부채·순자산·월차액·생활비/상환/기존납입포함관계정규화.
- 자금원장: 보유잔액/목적배정/월배분/가용일/최초사용일·지급일을분리. 비상금·목표·투자이중배정검사.
- 목표: 목표액/현재준비/사용시점/월선택납입·최소필요납입/부족액을구분.

- 불명값·정책미정·실행불가·기능미지원·입력오류를각각다르게반환.

완료기준: 대표입력/독립기대값/경계조건/가정과정책버전이있고,숫자일치뿐아니라중간현금부족/중복배정/누락/상한초과도검사한다. 앱테스트와재무타당성검토는별개다.

## 3. 화면 보완과 실제 수직 통합

새 화면을많이늘리는것이목표는아니다. 기존Stitch를재사용한다.

- 실제필수입력템플릿(생활비/금융자산/목표/기존납입/반복자산·채무).
- 투자0·월적자·보호금부족·목표일미정결과. 투자를억지제안하지않음.
- 전체금융자산의현재/재구성비교,신규자금과필요기존변경구분.
- 대표상품카드: 상품군·역할·위험·비용·유동성·출처·시점·지원상태. ETF에만고정하지않음.
- 재방문→이번달입력→계획비교→월말기록→변경초안→재채택. 원안/실제/수정안을분리.
- 빠른결과모바일전용내보내기가통합본에없음. 실제반응형을확인하고긴표/차트/하단CTA만추가설계.

작은수직기능첫예: 질문입력→확인된월차액→서버저장→현황표시. 다음목표부족액→배정가능상한→계획채택→실적을순차연결. 기존서버/API가있으면어댑터로연결하고전체재작성금지.
