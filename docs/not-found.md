# 얼어붙은 한강 고양이 404

## 사용자 요청과 범위

2026-11-01: 제공한 파란 겨울 404 일러스트를 참고해, '꽁꽁 얼어붙은 한강 위로 고양이가 걸어갑니다' 밈 느낌의 404 페이지를 구현한다. 기존 사진의 흑백 무늬를 반영한 2D 걷기 고양이를 사용한다.

## 완료 조건

- App Router의 `src/app/not-found.tsx`로 연결한다. 없는 주소는 이 화면을 표시한다.
- 커다란 HTML 404 숫자, 얼어붙은 한강/눈/다리/서울 스카이라인의 겨울 일러스트, 실제로 걷는 고양이 레이어를 조합한다. 문구와 링크는 이미지에 굽지 않는다.
- `홈으로 돌아가기`는 기존 계산기 `/`, `로그인 화면`은 `/login`으로 연결한다.
- 사용자는 고양이 걷기를 멈추거나 재생할 수 있다. 동작 줄이기·비활성 탭·화면 밖에서는 애니메이션을 멈추며 unmount 시 구독과 rAF를 정리한다.
- 320px 모바일에서도 가로 넘침과 텍스트/버튼 겹침이 없어야 한다.
- 이미지 오류 시에도 404 안내와 복귀 동선은 남는다. 금융 API나 회원 인증을 요구하지 않는다.

## 이미지와 구현

ImageGen으로 예시 스타일의 한강 배경만 생성하고 WebP로 압축했다. 사진을 참고해 만든 기존 투명 고양이 아틀라스를 별도 레이어로 움직인다. 사람·동물·문자 없는 배경과 고양이를 분리하여 404 문구의 접근성과 반응형 크기를 유지한다. 실제 한강 결빙 상태나 보행 안전을 안내하는 자료가 아닌 밈을 활용한 가상 일러스트다.

검증 결과와 한계는 개발 로그에 기록한다. 기존 걷기/로그인 변경도 유지하며 GitHub 업로드 제한은 별도 승인이 있기 전까지 유지한다.
